# Idea 7 — citation-neighbourhood sweep (Angle C)

Idea: quantization-cell theorem for requantized post-training deltas (unbiased, Var = Δ|d| − d², SNR ≈ mean|d|/Δ), unifying LoRA-merge failure, unlearning reversal and quantization-conditioned attacks; Design 1 = cell-aligned sparse deltas D ∈ {−Δ,0,+Δ}; Design 2 = secret-seed subtractive-dither quantizer as defense.

Method: fetched full text of the papers named in the idea (2405.18137, 2505.23786, 2605.15152, 2410.16454, 2309.14717, 2606.29239, 2606.20254, 2609.18063), grepped their reference lists and defense/theory sections, fetched the promising neighbours, ran 30+ arXiv API queries and 6 web searches. Paper text treated as untrusted data; quotes are verbatim from the fetched .txt files (paths under scratchpad/papers/<id>/).

## Headline findings (cold read)

1. **The uniform-offset premise fails in the main 2026 merge setting.** Theorem 7.1 assumes the base weight's in-cell offset u ~ U[−½,½). When the base is itself a dequantized 4-bit checkpoint (QLoRA/NVFP4/MXFP4 merge), u ≡ 0: the base is a fixed point of nearest rounding and any |d| below the half-step is deleted deterministically, not "unbiased + noise". Scale-QLoRA (2609.04526) states exactly this ("Claim (two cases, one reason)... an on-grid value is a fixed point of nearest-rounding, so re-quantizing W + ∆ returns W") and measures up to −39 pp. 2609.18063 §3.3 measures weight-level retention Σ(actual·δ)/Σδ² = 0.34 (attention proj.) and 0.02 (dense proj.) — this statistic is precisely the regression slope that Theorem 7.1 predicts to be ≈1. So Experiment 1 as written (QLoRA adapters → merge → requantize) sits in the regime where the theorem's unbiasedness is false. The "unification" needs a two-regime statement (FP base: unbiased/noisy; on-grid base: deterministic deletion). Attack (Egashira: FP base) and unlearning (Zhang: FP full-parameter) are in the uniform-offset regime; the merge literature mostly is not.
2. **Design 1 is largely built already.** LoTA-QAF (2505.18724) trains ternary adapters A_T,B_T ∈ {−1,0,1}, thresholds the product to Ŵ ∈ {−1,0,1}^{Din×Dout}, adds Ŵ to the integer codes W_int (i.e., ±1 code step = ±Δ in-group) with overflow prevention, trained by ternary signSGD, "lossless merging". MANSU (2605.15138) applies a per-parameter magnitude floor ≥ NF4 bin width to unlearning updates ("quantization survival by construction", Lemma 1) and formalizes a sparsity–permanence tradeoff (Prop. 1). What remains new in the idea: the SNR framing, the top-s projected/proximal ±Δ step for unlearning, the "SNR = ∞" durability proof, and the link to 1.58-bit delta compression.
3. **Design 2 (secret-seed subtractive dither as a defense) has no prior art found.** No arXiv or web hit for dither / stochastic rounding / randomized quantization used as a defense against quantization-conditioned backdoors. Closest: FlipGuard (2606.28962, deterministic pre-quantization perturbation of selected weights across the rounding midpoint), EFRAP (2405.12725, learned non-nearest rounding), QuantGuard (2606.29239, learnable rounding; also shows a defense-aware adaptive attacker that tightens the feasible intervals — the secret-seed argument is exactly what such an attacker cannot anticipate), Gaussian-noise defense (Ma et al. 2108.09187; Egashira 2405.18137 Table 6; broken by outlier injection in 2605.15152 Fig. 2). Dithered quantization of DNN weights itself is old (Choi et al. 1802.02271, universal randomized lattice quantization with shared dither seed) and the subtractive-dither error identity for quantized LLM matmul is in Sao 2607.18745. Caveat for the write-up: the Δ²/12 input-independent error requires *subtractive* dither (seed available at dequantization); non-subtractive random rounding gives Δ²/6-type error and is what a plain "stochastic rounding" kernel delivers.
4. **"No theory" for unlearning reversal is too strong.** Zhang et al. 2410.16454 §5 has a deterministic interval argument ("the weight changes in f_unlearn must exceed the quantization step size ∆"; int4 needs 12.5 vs int8 0.78 in their example). MANSU adds Lemma 1/Prop. 1/Prop. 2. None has the unbiased/variance/SNR statement; the idea's theorem corrects MANSU's "silently erased" (sub-bin updates are erased per element w.p. 1−|d|/Δ but survive in expectation).
5. **Competing explanation to test against:** 2609.27355 attributes quantization-fragile forgetting to sharp curvature of the forget-loss minimum (Theorem 1: L_r(w*) ∝ (λF_r/(F_r/F_f − λ))² d², g_f ∝ d) and fixes it with sensitivity-guided noisy regularization. A fair Experiment 2 should regress recovery on both SNR and a sharpness proxy.
6. **Empirical tension:** DurableUn (2605.02196) Appendix D: "merged-model NF4 deployment does not exhibit the INT4 recovery effect" (Llama-3-8B-Instruct, LoRA unlearning merged into BF16 base, bitsandbytes NF4), while merged INT8 shows partial recovery; their 22× recovery is in an adapter-space INT4 simulator. The SNR predictor must explain why Zhang (full-parameter, GPTQ/AWQ on Llama-2-7B) sees reversal and DurableUn (LoRA-merged, NF4) does not.
7. Citation fix: [2609.18063] is real (Lin et al., "The Other Half of the Memory Wall", 2026-09-16) and its §3.3 is the source of the "34% / 2% / 18%" numbers; the [U] tag can become [V].
