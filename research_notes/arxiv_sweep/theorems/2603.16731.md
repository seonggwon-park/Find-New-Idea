## Q1. Staleness ("stalling") model — exact statements and assumptions (Sec. 3, 4)

Set-up (Sec. 3, "Preliminaries"): generic EMA `x_t = β x_{t−1} + (1 − β) s_t` (Eq. 1). "the EMA state is stored in low precision but updated in high ... One update therefore reads x_{t−1} = D(x^q_{t−1}), forms the FP32 update x_t = βx_{t−1} + (1 − β)s_t, and writes back x^q_t = Q(x_t). Since D(·) is just a cast, no new quantization error is introduced during the read phase; all new errors enter on the write phase through Q(·)."

> "Definition 3.1 (State update stalling). We say that state update stalling occurs at step t if x^q_t = x^q_{t−1}. (2)"

Scope restriction: "We focus on the standard Adam setting ... Although the same gating mechanism applies to both moments, it is typically more pronounced for the second moment ... We therefore focus the analysis on the second-moment EMA." Single coordinate, `v_t = β2 v_{t−1} + (1 − β2) g_t²`.

Assumptions (Sec. 3.1), each stated as an approximation, not a hypothesis of a theorem:
1. Short-window local stationarity: "over the window of interest we assume that the coordinate has an approximately fixed local scale σ, and we analyze the EMA in the regime where v_{t−1} is of the same order as σ²."
2. Local Gaussian gradient: `g_t/σ ≈ N(0,1)`, `g_t²/σ² ≈ χ²₁` (Eq. 3).
3. Nearest-rounding stalling cell: stall iff `|Δ_t| < u_t/2`, `Δ_t = (1−β2)(g_t² − v_{t−1})` (Eqs. 4–5), `u_t = ulp(v^q_{t−1})`.
4. Floating-point relative spacing: `u_t = (ε/m_t) v^q_{t−1}`, ε = 2^−p with ε = 2^−7 (BF16), 2^−3 (E4M3 FP8), 2^−2 (unsigned E2M2 FP4 for the second moment) (Eq. 6).
5. "Effective-spacing approximation": replace mantissa m_t by m̄ = E[m_t] = 1/ln 2 "under a log-uniform mantissa model" (Eq. 7). "It is a representative-spacing approximation, not an exact averaging of the stalling probability."
6. Local-stationarity `v_{t−1} ≈ v^q_{t−1} ≈ σ²`, z_t := g_t²/σ² ≈ χ²₁ (Eq. 8).

> "Definition 3.2 (Effective precision ratio). We define ρ̂ := ε / (2(1 − β2) m̄). (11)"  With it, |Δ_t|/u_t ≈ |z_t − 1|/(2ρ̂) (Eq. 12) and the NR stall condition is |z_t − 1| < ρ̂ (Eq. 13).

> "Proposition 3.3 (NR stalling probability). Let z_t ∼ χ²₁. Under the effective-spacing approximation, the one-step probability of state-update stalling under nearest rounding is P^NR_stall(ρ̂) ≈ F_χ²₁(1 + ρ̂) − F_χ²₁(max(0, 1 − ρ̂)). (14)"

> "Corollary 3.4 (High-stalling regime under nearest rounding). When ρ̂ ≥ 1, the lower term in (14) vanishes, so P^NR_stall(ρ̂) ≈ F_χ²₁(1 + ρ̂). (15) ... once the EMA reaches its steady magnitude, most updates are blocked by the rounding gate."

Table 1 (β2 = 0.999, NR): BF16 ε=2^−7, ρ̂=2.71, P≈0.946; FP8 E4M3 ε=2^−3, ρ̂=43.3, P≈1.000; FP4 E2M2 ε=2^−2, ρ̂=86.6, P≈1.000.

Scale-invariance claim (after Table 1): "the ratio ρ̂ governing stalling depends only on the precision format and decay β2. As a result, changing the overall gradient scale, model width, or dataset shifts the EMA magnitude and floating-point spacing together, leaving the stalling probability essentially unchanged." NOTE: this relies on *relative* (floating-point) spacing — it does not hold for a fixed-step integer grid.

Effective decay (Sec. 4.1): "β2^eff ≈ 1 − (1 − β2)(1 − P_stall), (16)" and "τ_eff ≈ τ/(1 − P_stall) (17)", τ = 1/(1−β2).

Transient (Sec. 4.2), zero-initialised EMA, reference trajectory v_j^ref = σ²φ_j, φ_j = 1 − β2^j (Eq. 18):
> "Proposition 4.1 (Transient NR stalling probability). With z_t defined in (8), the transient stalling probability under nearest rounding is approximated by P^NR_stall(j) ≈ F_χ²₁((1 + ρ̂)φ_j), (19) for the formats of interest, where ρ̂ ≥ 1."
  (PDF extraction renders the argument as "F_χ²₁ (1 + ρ̂)ϕj"; the reading F_χ²₁((1+ρ̂)φ_j) is the one consistent with Prop. 4.3.)
> "Definition 4.2 (Startup window length). For a tolerance P0 ∈ (0, 1), define the startup window length as the smallest j such that P_stall(j) ≥ P0."
> "Proposition 4.3 (Ideal startup window). Let φ*(P0) := F^{-1}_χ²₁(P0)/(1 + ρ̂). Whenever φ*(P0) < 1, the ideal startup window is j*_ideal(P0) = ⌈ log(1 − φ*(P0)) / log β2 ⌉. (20)"  In practice a measured nonzero floor P_init is used.

Stochastic rounding (Sec. 5.1): "SR is unbiased without clipping and softens, but does not eliminate, stalling."
> "Proposition 5.1 (SR stalling probability). Under the effective-spacing approximation at steady state, with z_t as in (8), the conditional probability that SR returns to the current stored value is p^SR_stall(z_t; ρ̂) = max(0, 1 − |z_t − 1|/(2ρ̂)), (25) and hence P^SR_stall(ρ̂) = E[p^SR_stall(z_t; ρ̂)]."
Table 2 (β2 = 0.999, SR): BF16 0.825, FP8 0.989, FP4 0.994. "Thus SR materially helps at BF16, but at FP8 and FP4 the stalled regime remains dominant. This analysis isolates unchanged-state probabilities only; in practice SR may also help by reducing directional quantization bias."

Status (PROVED vs APPROXIMATED): every "Proposition" is a closed-form *approximation* under assumptions 1–6; nothing is a theorem with a rigorous error bound. The text sometimes calls them "Theorem 3.2/3.3/5.1/5.2" (e.g. "ratio ρ̂ in Theorem 3.2", "We derive Theorem 3.3", "adaptive rule based on Theorem 5.2") — inconsistent labelling; in the main text they are Definition 3.2 / Propositions. Empirical audit (App. A.5, Table 10, LLaMA-100M, 3,000 post-warmup iterations, NR, BF16/FP8/FP4): empirical mean mantissa 1.318 / 1.413 / 1.427 vs theoretical 1/ln 2 ≈ 1.443; median relative-ULP error 0.193 / 0.213 / 0.307 — i.e. the effective-spacing substitution is off by ~20–30% coordinate-wise ("a useful aggregate approximation rather than an exact coordinate-wise description").

## Q2. Reset prescription and evidence (Sec. 5.2, 6; App. A.9–A.12)

Mechanism claim: "once a quantized EMA becomes effectively stale, resetting it can temporarily restore responsiveness" (abstract). Reset = re-initialise the EMA (and its bias-correction age) to zero.

Rule. Normalised stalling progress `S(j) := (P_total(j) − P_init)/(P^ss_total − P_init) = P_stall(j)/P^ss_stall` (Eq. 26); cycle-averaged excess over tolerance s0, `S̄_{s0}(K) := (1/K) Σ_{j=1}^K [(S(j) − s0)/(1 − s0)]_+` (Eq. 27); remaining statistical error of the bias-corrected EMA `E(K) := 2β2^K/(1 + β2^K)` (Eq. 28, derived in App. A.9).
> "Proposition 5.2 (Reset period). Define K* := min{K ≥ 1 : S̄_{s0}(K) ≥ E(K)}. (29) Using P_stall(j) ≈ F_χ²₁((1 + ρ̂)(1 − β2^j)) and P^ss_stall ≈ F_χ²₁(1 + ρ̂) the condition in (29) is a one-dimensional monotone test in K. We use s0 = 0.6 throughout."
"which should be viewed as selecting a good operating region rather than a uniquely optimal period."
Table 3 (β2 = 0.999, s0 = 0.6): K* ≈ 1116 (BF16), ≈ 320 (FP8), ≈ 224 (FP4). Experiments round to 1000 / 300 / 200; "The first moment is reset with the same period." The rule is derived under NR but used with SR "as a practical proxy".
Status: Prop. 5.2 is a *definition of a heuristic stopping rule* with a hand-picked tolerance s0 = 0.6; there is no optimality statement.

Evidence (all C4 pre-training, LLaMA family, GaLore protocol; seq len 256, 131K-token batches; FP8 = E4M3 both moments with per-tensor scaling; FP4 = E2M1 first moment, E2M2 second moment, block 128, zero excluded, following Li et al. 2023):
- Table 4 (val loss, 60M/100M/350M; 10K/20K/60K steps; ~1.3B/2.6B/7.8B tokens): BF16 AdamW 3.52/3.27/2.99 vs +SR+Resets 3.45/3.21/2.92; FP8 3.53/3.33/3.02 vs 3.44/3.22/2.92; FP4 3.52/3.32/3.03 vs 3.48/3.26/2.97. NOTE: the treatment always bundles SR **and** resets.
- Table 5 (100M, FP32 training, only optimizer states quantized; NR only / SR only / Resets only / SR+Resets): FP32 3.155 / – / 3.161 / –; BF16 3.181 / 3.156 / 3.158 / 3.155; FP8 3.193 / 3.160 / 3.159 / 3.155; FP4 3.199 / 3.182 / 3.166 / 3.160; memory savings 0/50/75/87.5%. "applying the same reset schedule in full FP32 slightly hurts performance" (3.155 → 3.161, period 1000 both moments). This is the cleanest isolation of resets, and resets-only ≈ SR-only at BF16/FP8; resets matter more than SR only at FP4.
- Fig. 6: reset-period sweep, "performance is robust over a broad range, with the best results attained near the period predicted by Equation (29)" (figure only, no table).
- Table 6 (FP8, 100M): symmetric 3.223, asymmetric (no first-moment reset, 300 for second) 3.212, adaptive 3.225. "The adaptive rule matches, but does not improve upon, the tuned periodic schedule."
- Table 7 (SOAP): BF16 3.22 → 3.19; FP8 4.15 → 3.23.
- Table 14 (LLaMA-1B, 120K steps, ~16B tokens): BF16 2.91 → 2.77; FP8 2.89 → 2.78 (AdamW → AdamW+SR+resets). Table 15 (100M, 60K steps): BF16 3.162 → 3.044; FP8 3.223 → 3.098. These gains (0.12–0.14) are much larger than the Table 4 gains (0.04–0.11), and the BF16 baseline improves as much as FP8 — i.e. at 1B the reset+SR effect is not specific to the more-stalled format. Seeds/error bars not reported for these tables (zero-shot Table 16 uses 5 seeds).
- Single-run results throughout the main tables; no variance reported for Tables 4–7.

## Limitations (Sec. 8, verbatim)
> "Our analysis is designed to isolate a specific and practically important mechanism, state-update stalling under quantized EMA storage, rather than to model every aspect of low-precision training. As a result, some components are intentionally approximate, including the local scalar analysis of the EMA dynamics and the rule used to choose reset periods. These simplifications still match the main empirical trends well in our experiments, but the exact quantitative behavior can depend on implementation choices such as scaling strategy, rounding mode, and optimizer variant. In addition, our end-to-end study focuses on the LLaMA pretraining settings and EMA-based optimizers considered here. Extending the analysis to broader training regimes, larger scales, and additional classes of stateful optimizers is a natural direction for future work."
Conclusion: "motivates future work on optimizers and quantization schemes designed explicitly to remain responsive under quantization."

## Implications for the report (Idea 2, report line 125; also hypothesis (i)–(ii) and Math (1))
1. "동일 현상" is still in the report (the first-pass rewording was not applied). Replace with "an analogous write-back-rounding pathology (stalling) in quantized EMA optimizer states" and keep "[S]→ verified, preprint".
2. The report's deadband condition in Math (1), |(1−a_t)ĥ_{t−1} − u_t| < Δ/2 ⇒ freeze, is exactly the paper's Eq. 5 (|Δ_t| < u_t/2) with β ↔ a, (1−β)s_t ↔ u_t. Cite Eq. 5 / Def. 3.1 for it. The paper gives the quantitative version: for floating-point storage the stall probability is controlled by ρ̂ = ε/(2(1−β)m̄) (Def. 3.2), so it grows like 1/(1−a) — "slow channels stall" is a *quantitative* consequence, not just an intuition. But the closed form (Prop. 3.3) relies on the χ²₁ model of a *squared gradient* input and on floating-point *relative* ULP; for an SSM with signed inputs u_t and a fixed INT step Δ (the report's setting) neither holds, and the scale-invariance claim fails (stall probability then depends on |ĥ|/Δ). Say so explicitly.
3. The paper does NOT support hypothesis (ii) "SR variance diverges as Δ²t/12". Its SR result (Prop. 5.1, Table 2) is about stall probability (0.825/0.989/0.994 at β2 = 0.999) and it states SR "softens, but does not eliminate, stalling"; nothing about variance growth. Don't cite it for (ii).
4. The paper's remedy is periodic resets (Prop. 5.2, a heuristic rule with s0 = 0.6, K* ≈ 1116/320/224) bundled with SR; it does not study error feedback / ΣΔ. So it is prior art for the *diagnosis* (freeze under RTN write-back of a first-order recursion, partial relief from SR) and leaves the report's proposed fix (error feedback) open. A reset has no direct SSM analogue (zeroing an SSM state destroys context), which strengthens the case for error feedback — state that as the report's argument, not the paper's.
5. If the report quotes magnitudes, use: BF16 β2=0.999 NR stall ≈ 0.946 (Table 1); FP8/FP4 ≈ 1.000; FP32-training isolation gains in Table 5 are ≤ 0.04 nats at 100M scale.
6. Mark all "propositions" as approximations (the paper itself: "intentionally approximate").
