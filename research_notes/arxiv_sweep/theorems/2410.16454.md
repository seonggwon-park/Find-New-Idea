# 2410.16454 — Catastrophic Failure of LLM Unlearning via Quantization (Zhang et al., ICLR 2025)

Text: scratchpad/papers/2410.16454/2410.16454.txt (line numbers below refer to it; paper text quoted as untrusted data).
First pass (verify/batch_02.md) already confirmed: existence, ICLR 2025, 21%->83% verbatim, SURE is module-level, no Theorem/Lemma. This note goes deeper.

## 1. What is PROVED vs CLAIMED vs MOTIVATED
- PROVED: nothing. No theorem, lemma, proposition, bound or probability statement. The abstract and App. K call Sec 5 a "theoretical analysis/explanation"; it is an informal interval argument.
- Sec 3.1 Eq. (2) (L265-276): "consider a group or block of weights w ... Q(w) = ∆ · Round(w/∆), ∆ = max(|w|)/2^{N−1}, where N is the number of quantization bits, and ∆ is the quantization scale factor (step size) determined by the absolute maximum value of w." (symmetric absmax; group size never specified for the RTN experiments).
- Sec 5 Eq. (3) (L767-790): I_i = [(i − 1/2)∆, (i + 1/2)∆); "∆int4 = max(|w|)/2^{4−1} = max(|w|)/8, and ∆int8 = max(|w|)/2^{8−1} = max(|w|)/128".
- Key sentence (L807-810): "To differentiate the quantized weights of the original model f from those of the unlearned model funlearn, the weight changes in funlearn must exceed the quantization step size ∆. ... effective unlearning methods that preserve utility typically have minimal weight changes, resulting in ftarget and funlearn being highly similar, i.e., Q(funlearn) ≈ Q(ftarget)."
- Worked example (L816-826, Fig. 2, max|w| = 200): "only when weight changes exceed 12.5, int-4 quantized models will reflect these differences. By contrast, int-8 quantization only needs a small change of 0.78125".
- Critical reading: the "must exceed ∆" condition is neither necessary nor matched by its own example. A weight at offset u inside its cell flips with a change of size (1/2 − u)∆ or less; the 12.5 = ∆/2 example is the worst case for a weight at exactly 0. Under a uniform-offset assumption the flip probability is |d|/∆ (this is the report's Thm 7.1, not the paper's). The paper never measures weight-change magnitudes, ∆ per group, or the fraction of quantization codes that change after unlearning (grep for "fraction of"/"proportion of weights"/"quantized value" finds only the definitional lines). So the link "small LR -> |Δw| << ∆ -> Q(f_unlearn) = Q(f_target)" is asserted, not measured.
- Sec 3.2 (L286-293) motivation is purely the LR comparison: MUSE peak LR 1e−5, TOFU 1e−5/1e−6/5e−7, RWKU 1e−8..1e−5 vs Llama3-8B 3e−4 etc.

## 2. Numbers (Q1/Q2)
- Abstract + Sec 4.2 (L601-604): "for unlearning methods with utility constraints, the unlearned model retains an average of 21% of the intended forgotten knowledge in full precision, which significantly increases to 83% after 4-bit quantization."
- How 21/83 is aggregated is NOT defined in the paper. I could not reproduce it exactly from Table 1 (4 constrained methods x 2 datasets, ratios to target). Closest: mean over {M1 VerbMem, M2 KnowMem} of unlearned/target with FP normalised by FP target and 4-bit by 4-bit target = 23.2% / 86.4%; M2 only = 36.6%/93.0%; M1 only = 9.9%/79.9% (my computation, scratchpad/t1.py). Treat 21/83 as an un-specified aggregate.
- Models (App. C.3, L1639-1641): NEWS uses LLaMA-2 7B; BOOKS uses ICLM-7B. Benchmark MUSE (NEWS, BOOKS); RWKU in App. F (Table 7). Methods: GA, GA_GDR, GA_KLR, NPO, NPO_GDR, NPO_KLR (+ RMU-type methods in App. J, Table 11).
- Quantization: 4-bit RTN for Q1 (L593); AWQ and GPTQ 4-bit in Table 2 (NEWS); 8-bit RTN in Table 1. 2-bit excluded "due to their big performance gap" (L611).
- Table 1, NEWS M1 VerbMem / M2 KnowMem (FP -> 8-bit -> 4-bit):
  - Target 58.4/63.9 -> 40.8/66.4 -> 34.2/54.4; Retrain 20.8/33.1 -> (4-bit) 18.5/36.0
  - GA_GDR 0.0/28.9 -> 0.0/26.9 -> 25.0/50.1; GA_KLR 14.1/27.1 -> 15.3/29.0 -> 33.8/50.9
  - NPO_GDR 0.3/46.1 -> 0.1/44.2 -> 33.2/51.4; NPO_KLR 16.6/36.6 -> 17.0/37.2 -> 34.1/53.7
  - GA all 0.0 with M4 utility 0.0 ("misleading as it results from a complete loss of model utility").
- Table 1, BOOKS M1/M2: Target 99.8/59.4 -> 99.0/45.1 -> 85.3/36.8; GA_GDR 0.0/2.9 -> 0.8/3.7 -> 17.9/33.7; GA_KLR 13.0/15.1 -> 12.4/10.1 -> 75.6/34.6; NPO_GDR 0.4/13.4 -> 0.9/14.0 -> 66.0/31.9; NPO_KLR 12.4/13.7 -> 11.7/11.2 -> 70.9/34.2.
- 8-bit (Sec 4.3, L613-614): "models with 8-bit quantization perform similarly to full-precision models due to 8-bit's greater sensitivity to weight changes." Confirmed by the rows above (unlearned 8-bit ≈ FP). App. L1730: target shows "a slight performance drop at 8-bit and a substantial drop at 4-bit". Note: Target NEWS M1 drops 58.4 -> 40.8 at 8-bit RTN, a large swing for 8-bit, which suggests the generation-based ROUGE metrics are noisy at the scale of the effects.
- Notable: 4-bit unlearned BOOKS M2 (31.9-34.6) is at or ABOVE the 4-bit target (36.8 is only slightly higher); i.e. 4-bit essentially erases the unlearning on KnowMem.

## 3. SURE (Sec 6.1, Eqs. 4-6)
- Rationale (L885-900): objectives (i) unlearn, (ii) preserve utility, (iii) prevent recovery via quantization; "the core issue ... lies in the fact that effective unlearning seeks minimal weight changes to preserve model utility. This creates a conflict between objectives (ii) and (iii)." Large LR for both losses risks "over-adjustment" and bias to retain set (App. I).
- Eq. (4): s_i = ||∇_{θ_i} L_forget(θ; D_forget)|_{θ=θ_o}|| (Frobenius norm per module; module = "a specific attention head or feed-forward sub-layer"). Eq. (5): m_M[i] = 1 if s_i ≥ γ else 0. Eq. (6): θ_u = θ_o + m_M ⊙ ∆θ. Name: "Saliency-Based Unlearning with a Large Learning Rate (SURE)" (L948).
- Grid (L970, L1130): LR ∈ {5e−5, 1e−4, 2e−4}; α ∈ {1, 20, 100, 300, 400}; γ ∈ {Percentile(s,90), 95, 99}. Ablation SURE/S (no saliency, LR 1e−4, Table 10): forgets more but worse utility.
- The paper does NOT check that SURE's weight changes exceed ∆ (no |Δw|/∆ statistics); the mechanism remains a hypothesis tested only by the end metric. App. K (L2215-2226) is explicit: "we identify increasing weight changes as a promising approach ... our results in Table 3 demonstrate that this approach shows promise"; "this is not the only approach ... Our aim here is to make an initial effort".
- Table 3 (BOOKS, 4-bit) M1 VerbMem: GA_GDR 17.9 -> SURE 0.0; GA_KLR 75.6 -> 16.4; NPO_GDR 66.0 -> 0.0; NPO_KLR 70.9 -> 16.1. M2 KnowMem 4-bit: GA_GDR 33.7 -> 4.8; GA_KLR 34.6 -> 28.4; NPO_GDR 31.9 -> 24.4; NPO_KLR 34.2 -> 36.9 (WORSE with SURE). So the "significantly improves forgetting" claim is driven by VerbMem; KnowMem improvement is mixed and for NPO_KLR absent. FP KnowMem with SURE is also worse for NPO_KLR (22.7 -> 37.8).
- Inconsistency: Table 3's FP baselines differ from Table 1 for the same methods (BOOKS M1 GA_KLR 23.8 vs 13.0; NPO_GDR 3.2 vs 0.4; NPO_KLR 22.6 vs 12.4; M2 GA_KLR 25.1 vs 15.1) while the 4-bit rows match (75.6, 66.0, 70.9). The paper does not explain this (probably different hyperparameter selection).
- Utility cost (L1138-1142): GA_GDR + SURE "leads to a utility drop in terms of factuality and truthfulness" (Table 3; the flattened PDF text of the Tru/Fac columns is too garbled to quote exact values reliably).

## 4. Own limitations / future work
- App. K: SURE is "an initial effort"; saliency+large LR "is not the only approach"; "inspire future research aimed at increasing weight changes during unlearning".
- App. L (L2230-2235): "the problem of knowledge recovery via quantization pervasively exists only in 4-bit quantization".
- Abstract/Sec 7: a "fundamental tension between preserving the utility of the unlearned model and preventing knowledge recovery through quantization".
- Single 7B backbones, single seed (no error bars reported), group size of RTN unspecified.

## 5. What the report must change
- L288: "SURE(salient 가중치에 큰 LR)" -> "SURE(forget-loss 기울기 Frobenius 노름 기반 모듈(어텐션 헤드/FFN 하위층) 단위 saliency 마스크 + 큰 LR 5e−5~2e−4)". "이론은 없다" -> "정리·부등식은 없고, Sec 5는 'Δw가 ∆를 넘어야 양자화 코드가 바뀐다'는 비형식적 셀 논증(∆int4 = max|w|/8 vs ∆int8 = max|w|/128)이 전부; 가중치 변화량/코드 변경률은 측정하지 않았다". Tag [V].
- State the 21%/83% as the paper's unspecified aggregate over constrained methods on MUSE (LLaMA-2 7B NEWS, ICLM-7B BOOKS), 4-bit RTN; 8-bit RTN ≈ FP. Do not present it as a single-metric ratio.
- Idea 7 should cite this paper's "must exceed ∆" sentence as the strawman its Thm 7.1 sharpens (flip probability |d|/∆, not a threshold), and note the paper never measured |Δw|/∆ or code-flip rates: that measurement is genuinely open and is experiment 2 of Idea 7.
- Mention that SURE's 4-bit KnowMem gain is mixed (NPO_KLR worse: 34.2 -> 36.9), so "SURE가 완화한다" should be "VerbMem 기준으로 크게 완화, KnowMem은 방법에 따라 혼재".
