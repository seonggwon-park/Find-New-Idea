## 0. Setup the theorems live on (Section 2, "Linear-Layer Quantization Problem")

> "Let X = [x1, ..., xn]ᵀ ∈ R^{n×c} be the sampled calibration input data of batch size n and input dimension c with xi ∈ R^c and **n ≥ c = rank(X)**. Let W = [w1, ..., wr] ∈ R^{c×r} be the linear layer weights ... Let S = [s1, ..., sr] ∈ R^{c×r}_{≠0} be the non-zero quantization scales ... each weight element wi[j] has its own scaling factor si[j]. **Assume S is statically computed using methods like AbsMax or MSE before any weight updates.** Let Z† ⊆ Z be the quantization grid (representable integers). In the clipping setting, e.g., for INT4 format, Z† = {−8, ..., 7}. In the no-clipping setting, Z† = Z ... The goal is to minimize the L2 error on the layer output XW ∈ R^{n×r}: ‖XQ − XW‖²_F = Σ_i ‖X diag(si) zi − X wi‖², i.e., finding argmin_{zi ∈ Z†^c} ‖X diag(si) zi − X wi‖² for all 1 ≤ i ≤ r."

So the whole paper is about the per-output-channel layer-wise L2 output error (the "proxy" objective). Nothing in the paper concerns end-to-end loss, activations, or KV cache (those are explicitly future work, see §6 below).

Babai's bound as the paper states it (Section 3.2, "Babai's error bound"): with Ã = [ã1, ..., ãc] the unnormalized Gram–Schmidt vectors of the (LLL-reduced) basis A, "|ζ − z[j]| ≤ 1/2 ... ‖y′‖² ≤ ¼ Σ_{j=1}^{c} ‖ãj‖² ... Babai's algorithm guarantees to return the center vector of the hyper-cuboid constructed by the unnormalized Gram-Schmidt vectors Ã where the target y is located. Equality is attained when the target y lies at the corner of the hyper-cuboid, so the bound is tight. Babai (1986) additionally proved a relative error bound for γ with ‖Bz − y‖ ≤ γ · min_{z′} ‖Bz′ − y‖. The bound is 1 ≤ γ ≤ sqrt(1 + max_{1≤j≤c} Σ_{j′=1}^{j} ‖ãj′‖² / ‖ãj‖²) ≤ √(c+1) · max_{1≤j′≤j≤c} ‖ãj′‖/‖ãj‖."

## 1. Equivalence theorem — Q1

Three statements build the equivalence (Section 4.1–4.3):

**Theorem 1 (Quantization and CVP), Section 4.1.** "The CVPs using any possible factors 𝒳 of the Hessian matrix XᵀX are equivalent under an orthogonal transformation (rotation and reflection) of the lattice and external target vector." (So the lattice can be built from any square root of the Hessian, e.g., a c×c Cholesky factor, instead of the n×c data matrix.)

Lattice dictionary (Table 1, Section 4.1, per output channel i): lattice basis B(i) = X diag(si) ∈ R^{n×c} (columns are generators; activations are basis directions, scales are "basis stretches"); target y(i) = X wi ∈ R^n; integer coordinates zi ∈ Z†^c; dequantized weight qi = diag(si) zi. Prose: "A quantization problem with the L2 objective argmin_{zi∈Z†^c} ‖X diag(si) zi − Xwi‖² and a CVP with the L2 distance argmin_{z∈Z^c} ‖Bz − y‖² share the same solution (z = zi) whenever the structural conditions B = X diag(si) and y = Xwi hold and the solution domain matches. To ensure the solution domain matches, we can either disable the clipping in the quantization setup (setting Z† = Z) or enable the clipping in the CVP setup (making z ∈ Z†^c)."

**Theorem 2 (Error Propagation and Babai's Projection), Section 4.2.** "Babai's nearest plane algorithm iteratively projects the target vector onto the nearest hyperplane and rounds the coefficient. The OBQ error propagation step (Eq. 2) is exactly this projection on the original basis B = X diag(si) without basis reduction."

**Theorem 4 (GPTQ and Babai), Section 4.3 — the equivalence.**
> "Originally, GPTQ (Algorithm 1) runs from the first to the last dimension (j ← 1 to c) while Babai's algorithm (Algorithm 2) runs from the last to the first dimension (j ← c to 1). This is the only (superficial) difference between the two algorithms, as formalized below.
> **Theorem 4 (GPTQ and Babai)** GPTQ and Babai's algorithm without basis reduction will have the same results if we align the dimensional order of these two algorithms, e.g., running GPTQ from the last to the first dimension."

Proof structure (Section 4.3 + Appendix C, three steps): "First, we rewrite GPTQ to track the cumulative quantization error and show that this form is algebraically equivalent to the standard implementation. Second, we run GPTQ in the back-to-front order and replace the lower triangular factor with an upper triangular one so that each update affects only the not-yet-quantized coordinates. Third, we prove that the step-wise rounding decisions of the back-to-front GPTQ coincide with those of Babai's algorithm." Babai's algorithm as instantiated for quantization is Algorithm 4 (Appendix B): H ← Tᵀ(XᵀX + λI)T, A ← Cholesky(H), scales permuted to T⁻¹S, rounding ROUND(ζ, Z†).

Assumptions / scope of Theorem 4, read off the setup and Appendix B:
- Ordering: GPTQ run **back-to-front** (last to first dimension) in whatever permuted order T it uses; equivalently "the permutation matrix of the reversed GPTQ quantization order".
- Lattice basis: the **un-reduced** basis X diag(si) (or any Hessian factor by Theorem 1), permuted by an i-independent permutation T. **No LLL/BKZ basis reduction** — the equivalence is specifically to Babai *without* reduction.
- Clipping: the equivalence holds **with or without** clipping. Contribution (ii), Section 1: "the GPTQ algorithm executed from the last to first dimension is the same as Babai's nearest plane algorithm on the basis of the factorized Hessian matrix, without LLL basis reduction, and this finding holds independently of whether large weights are clipped to the quantization grid". (Both algorithms round with ROUND(·, Z†), so clipping is simply a shared rounding rule.)
- Scales static (fixed before updates), per-element scales allowed (any grouping), n ≥ c = rank(X); dampening λI enters the Hessian in both algorithms (Algorithm 1 line 1, Algorithm 4 line 1).
- Tightness of the identification (Section 4.3 "Ineffectiveness of composing algorithms", proof Appendix C.4): "once Babai's projection has been executed, any subsequent GPTQ-style correction is algebraically redundant. This confirms that the equivalence in Theorem 4 is already tight; neither algorithm can be strengthened by composition."
- Theorem 6 (Appendix B, "Babai's Quantization Order"): "If T is a permutation matrix that does not depend on i, the orthogonal matrix Φ can be reused without recomputing the QR decomposition for each i." This is what makes the batched (all output channels at once) Babai = GPTQ with a shared inverse-Hessian factor work.

Geometric reading (Section 4.3): "GPTQ performs an orthogonal walk through a nested sequence of affine subspaces in a pre-computed dimensional order."

## 2. Error bound — Q2

**Theorem 5 (GPTQ Error Bound), Section 4.4; proof Appendix D.1.**
> "Assume no clipping (Z† = Z) and let T be the permutation matrix of the reversed GPTQ quantization order (equivalently P with the reversed column order). Let D be the diagonal matrix of the LDL decomposition of the permuted Hessian matrix TᵀXᵀXT. For every output channel i (1 ≤ i ≤ r) produced by Babai's algorithm, or equivalently the GPTQ algorithm executed back-to-front, the (absolute) quantization error has a tight upper bound:
>   ‖X diag(si) zi − X wi‖² ≤ ¼ (T⁻¹si)ᵀ D (T⁻¹si).
> For the relative bound for γ with ‖X diag(si) zi − Xwi‖ ≤ γ · min_{zi′ ∈ Z^c} ‖X diag(si) zi′ − Xwi‖, we have
>   1 ≤ γ ≤ sqrt(1 + max_{1≤j≤c} Σ_{j′=1}^{j} d_{j′}² / d_j²) ≤ √(c+1) · max_{1≤j′≤j≤c} d_{j′}/d_j,
> where d_j = sqrt(D[j,j]) · |(T⁻¹si)[j]|."

Proof sketch (Appendix D.1, exact quote): "Applying permutation T gives the permuted basis A(i) = B(i)T = X diag(si) T = XT diag(T⁻¹si). Write the unnormalized Gram-Schmidt vectors of A(i) as Ã(i) = [ã(i)1, ..., ã(i)c]. Babai's guarantee therefore yields the tight bound ‖B(i)zi − y(i)‖² = ‖A(i)T⁻¹zi − y(i)‖² ≤ ¼ Σ_j ‖ã(i)j‖². We may, without loss of generality, use Theorem 1 to rotate X so that A(i) is upper triangular. In that case, the norm ‖ã(i)j‖ simplifies to |A(i)[j,j]|. Let D(i) be the diagonal matrix of the LDL decomposition of A(i)ᵀA(i) such that D(i)[j,j] = A(i)[j,j]² = ‖ã(i)j‖². ... D(i) = diag(T⁻¹si) D diag(T⁻¹si) ... The absolute no-clipping error bound is therefore ¼ Σ_j ‖ã(i)j‖² = ¼ tr(D(i)) = ¼ (T⁻¹si)ᵀ D (T⁻¹si)."

So: Gram–Schmidt norms squared of the scaled, permuted activation basis = diagonal of the LDL of the scaled, permuted Hessian; the bound is ¼ × (scale-weighted trace of D).

Assumptions of Theorem 5:
1. **No clipping, Z† = Z** — explicit in the statement. Section 5 adds: "The original GPTQ algorithm clips the overflowed integers at the rounding step, introducing large errors that violate the error bound in Theorem 5." So the bound does NOT cover standard INT4 GPTQ with clipping.
2. GPTQ executed back-to-front (equivalently Babai) with an i-independent permutation T; D is the LDL diagonal of TᵀXᵀXT (the statement writes the un-dampened Hessian; the algorithms use XᵀX + λI, so in practice D is from the dampened Hessian and the bound is for the dampened objective).
3. Scales static; n ≥ c = rank(X).
4. Tight: equality when the target lies at a corner of Babai's hyper-cuboid (Section 3.2).
5. Average case (Section 4.4, proof Appendix D.2, Eq. 63): "If the scales si are small enough, we may assume the weights wi are nearly uniformly distributed within the hyper-cuboid constructed by Babai's orthogonalized basis vectors, the expected absolute error will be 1/3 of the worst-case bound." D.2: E‖X diag(si) zi − Xwi‖² = (1/12) Σ_j ‖ãj‖².

**Critical remark (mine, not the paper's).** With si ≡ 1 this absolute bound is exactly QuIP's Theorem 1 worst-case (m/4)·tr(D) for LDLQ, and the 1/12 average case is QuIP's (m/12)·tr(D) for nearest rounding (see note 2307.13304.md). The paper's Related Work only says "QuIP (Chee et al., 2023) proves an error guarantee for GPTQ and proposes the LDLQ method as an equivalent variant of GPTQ"; it does not state that Theorem 5's absolute bound coincides with QuIP's. What is new relative to QuIP: (a) the Babai identification and geometric interpretation, (b) the per-channel scale weighting (T⁻¹si)ᵀ D (T⁻¹si), (c) the **relative** approximation ratio γ against the optimal CVP solution, (d) the explicit tightness claim, (e) the order analysis (min-pivot). The report should not present "GPTQ=Babai" as an independent second guarantee on top of QuIP's — it is the same ¼·tr(D) proxy-loss bound re-derived.

## 3. Act-order and lattice basis reduction — Q3

### 3a. Quantization order / act-order (Section 4.5, Appendix D.3, Table 2)

> "The quadratic form on the right-hand side of the absolute error bound in Theorem 5 is sensitive to the pivot order of the LDL decomposition of the Hessian matrix; this is the quantization order. ... A poor order may place large D entries against large si entries and hence inflate the bound. For a batched quantization algorithm like GPTQ, the order should be independent of the output channel i. ... a reasonable approximation to make, especially for large quantization group sizes, is that the elements of si[j] are equal for all 1 ≤ j ≤ c. Then we can focus on finding the optimal pivot order for the LDL decomposition of the Hessian matrix XᵀX to minimize tr(D).
> Finding the optimal order is NP-hard (Rose et al., 1976). However, heuristics often effectively reduce the trace term in practice. Even with clipping, heuristics can reduce the error. GPTQ introduces the act-order, the descending order of the Hessian diagonal, i.e., the ascending order of the Hessian diagonal when applied to Babai's algorithm.
> To improve upon act-order, we propose the min-pivot order, which is essentially taking the minimum diagonal entry at each LDL (or Cholesky) decomposition step. This order can be calculated by Algorithm 3, which has cubic time complexity ... This order also has a geometric interpretation, as the order of the Gram-Schmidt orthogonalization process of the basis: always taking the shortest residual vector as the next one to orthogonalize, agreeing with Babai's relative error bound. Across our preliminary runs (Section D.3), min-pivot consistently reduces tr(D) relative to act-order, but the downstream accuracy gains are modest. We nevertheless report min-pivot as a principled choice, and view act-order as a cheap approximation that only considers the Hessian diagonal, which already captures most of the benefit when the Hessian matrix is well-conditioned."

Table 2 (Appendix D.3), tr(D) for Qwen3-8B transformer block 18 (calibration from Section E.2; random order averaged over 100 runs):

| Order | Q·K·V | O | Gate·Up | Down |
|---|---|---|---|---|
| back-to-front | 1.169e+08 | 1.824e+08 | 1.181e+08 | 1.323e+09 |
| front-to-back | 1.161e+08 | 1.841e+08 | 1.202e+08 | 1.320e+09 |

D.3 text: "act-order already reduces tr(D) relative to the back-to-front/front-to-back/random baselines, especially in the Q·K·V and Gate·Up layers (≈35-50% lower). Our min-pivot heuristic consistently attains the smallest trace. In practice, this tightens the theoretical layer-wise error bound and yields modest but consistent improvements. We can use act-order as a cheap option and reserve min-pivot for cases where a tighter bound is required." (min-pivot improves tr(D) over act-order by only ~1% in Table 2; no downstream-accuracy table for min-pivot vs act-order is given — all Section 5 experiments use act-order: "The quantization order is act-order for all methods.")

Status: act-order's benefit is **explained** (it lowers tr(D)) and **measured** at the tr(D) level; the accuracy benefit of min-pivot is only described as "modest" in prose. Note the paper's own caveat that the tr(D) proxy assumes roughly uniform scales within a group.

### 3b. Lattice basis reduction (LLL/BKZ) — motivated, NOT implemented

- Related Work (Section 2): "Babai's nearest plane heuristic (Babai, 1986) delivers a solution in polynomial time and, when preceded by LLL basis reduction (Lenstra et al., 1982), enjoys a 2^{O(n)} approximation. BKZ basis reduction (Kannan, 1987) further tightens the constant in an exponential-time solver."
- Appendix B, "Disabling basis reduction": "A naive way is to compute B(i) = X diag(si) and y(i) = X wi and run Babai's algorithm independently for all 1 ≤ i ≤ r. However, this is computationally inefficient, as we will need to compute the expensive (O(c⁴)) LLL basis reduction transformation T(i) for the basis B(i) and the expensive (O(c³)) QR decomposition of A(i) = B(i)T(i) for r times. ... **The LLL basis reduction is unfortunately scale-sensitive, generating different transformations T(i) for different scales si (unless all the si vectors are parallel), which prohibits the reuse of QR decomposition results. Furthermore, LLL basis reduction is incompatible with clipping, as the roundings are performed in another basis, and there is no easy way to do the clipping for the original basis.**" They therefore "replace the LLL basis reduction in Babai's algorithm with a permutation by setting the transformation matrix T to a permutation matrix that is independent of i."
- Closing Remarks (Section 6): "the lattice perspective opens a two-way channel: decades of the closest vector problem (CVP) heuristics can refine practical quantizers" and Future work: "exploring (scale-aware) basis reductions are the immediate next steps."
- Abstract: "open the door to importing decades of progress in lattice algorithms towards the design of future quantization algorithms."

Bottom line: the paper contains **no experiment and no theorem** about LLL/BKZ-reduced quantization. Basis reduction is (i) explicitly disabled to obtain the GPTQ equivalence, (ii) flagged as scale-sensitive and clipping-incompatible, and (iii) named as future work. Anyone citing this paper for "basis reduction gives a better GPTQ" is citing a motivation, not a result.

## 4. Empirical claims (Section 5, Appendix E) — author self-reported

Methods proposed to stay in the no-clipping regime where Theorem 5 applies: SSQR (scale-adjusted SpQR: per-group scale tuned by binary search so that overflowed weights after GPTQ propagation are stored as sparse FP outliers at a target rate 1–5%) and HPTQ (single scalar scale per matrix, unclipped integers, Huffman-coded; scale chosen by entropy-guided binary search to meet a target average bitwidth). Caveat stated by the authors: "enforcing no-clipping by simply increasing scales is counterproductive: larger scales enlarge the bound, and the resulting errors can exceed those of a clipped scheme such as MSE."

Setup (E.2): calibration 256 × 2048-token sequences from FineWeb-Edu; eval WikiText-2 and C4 at 2048 context; act-order for all methods; RTN/GPTQ/SSQR group size 128 with MSE scales.

## 6. The paper's own limitations / future work (close paraphrase + quotes)

- Section 6, Future work (verbatim): "Looking ahead, extending the analysis to clipped grids and exploring (scale-aware) basis reductions are the immediate next steps. However, we emphasize that the state-of-the-art 4-bit floating-point formats (e.g., MXFP4 and NVFP4) are essentially no-clipping (Egiazarian et al., 2025; Chen et al., 2026): since they use very small quantization groups (32 and 16, respectively), the near-optimal choice of scale is AbsMax per-group, which leads to no weight being clipped. As such, a no-clipping analysis of these formats would directly apply to actual practice. We will also extend the lattice view beyond weight-only linear layers to activation and KV-cache quantization."
- The error bound requires no clipping; original GPTQ (INT4 with clipping) "introduc[es] large errors that violate the error bound in Theorem 5" (Section 5).
- Enforcing no-clipping by enlarging scales "is counterproductive: larger scales enlarge the bound" (Section 5) — the bound is scale-weighted, so it is only meaningful at small scales, which forces outlier handling (SSQR sparse outliers / HPTQ entropy coding).
- Order optimization: "Finding the optimal order is NP-hard (Rose et al., 1976)"; min-pivot "consistently reduces tr(D) relative to act-order, but the downstream accuracy gains are modest" (Section 4.5); the tr(D) proxy assumes equal scales within the group.
- LLL basis reduction: O(c⁴), "scale-sensitive", and "incompatible with clipping" (Appendix B) — hence not used.
- The 1/3-of-worst-case average error assumes weights "nearly uniformly distributed within the hyper-cuboid" when "scales si are small enough" (Section 4.4 / D.2).
- Scope: weight-only, linear layers, layer-wise L2 output objective; static scales; n ≥ c full-rank calibration.
- Competitor numbers in Table 16 are copied from the competitors' papers, not re-run.

## 7. What the report must change

Current citation (reports/LLM 양자화 연구 아이디어 10선.md, line 38, Section 0.2 item 1): "[GPTQ=Babai 2507.18553](https://arxiv.org/abs/2507.18553) [S]" used as evidence that rigorous theory sits on the layer-wise MSE proxy.

1. Tag upgrade [S] → [V]; add venue "ICLR 2026" (confirmed from the full text and arXiv metadata).
2. The claim it supports is correct and can be made sharper: the paper's objective is exactly ‖XQ − XW‖²_F per output channel (Section 2), and the authors themselves list "activation and KV-cache quantization" and "end-to-end" bridges as not covered (Section 6). This strengthens item 1 and item 4 of Section 0.2 (no KV theorems), but the report should note that Chen et al. announce a lattice-view extension to activation/KV quantization as future work, so the gap may close.
3. Do not list "GPTQ=Babai" as a *separate* theoretical guarantee from QuIP's incoherence/LDLQ result: the absolute bound ¼ (T⁻¹si)ᵀ D (T⁻¹si) reduces to QuIP's (m/4) tr(D) worst case when si ≡ 1 (and 1/12 tr(D) average case). The genuinely new theoretical content is (a) Theorem 4 (back-to-front GPTQ ≡ Babai without basis reduction, holds with or without clipping), (b) the relative approximation ratio γ ≤ √(c+1)·max d_{j′}/d_j, (c) the order/min-pivot analysis. If the report wants to cite "GPTQ has a worst-case proxy-error bound", it should cite QuIP Thm 1 and 2507.18553 Thm 5 together and state the shared assumption: **rounding to the unbounded integer grid, no clipping**.
4. Any report text implying standard (clipped INT4) GPTQ "inherits Babai's bound" must add the no-clipping condition; the authors state that clipped GPTQ violates Theorem 5. Conversely, the authors' remark that MXFP4/NVFP4 with per-group AbsMax are "essentially no-clipping" is a useful bridge if the report discusses FP4 formats — that is where this bound applies in practice.
5. If any idea in the report proposes LLL/BKZ basis reduction for weight quantization: this paper does not test it; it names two obstacles (scale-sensitivity breaks QR sharing across output channels; incompatibility with clipping) and calls "(scale-aware) basis reductions" the immediate next step. That is open territory, not prior art — but Birnick 2508.01077 and this paper's Section 6 should both be cited as the motivation.
6. Act-order: the report can now cite a precise mechanism — act-order ≈ greedy reduction of tr(D) of the pivoted LDL (Table 2: ~35–50% lower tr(D) on Q·K·V and Gate·Up vs. natural order for Qwen3-8B block 18); the "optimal" order is NP-hard; min-pivot gives only ~1% further tr(D) reduction and "modest" accuracy gains.
