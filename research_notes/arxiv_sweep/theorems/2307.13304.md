## 0. Setup the theorems live on (Section 3, Eq. 1–4)

Proxy objective, Eq. (1), Section 3:
> ℓ(Ŵ) = E_x ‖(Ŵ − W)x‖² = tr((Ŵ − W) H (Ŵ − W)ᵀ)
> "W ∈ R^{m×n} is the original weight matrix for a given linear layer, Ŵ ∈ R^{m×n} are the quantized weights, x ∈ R^n is an input vector drawn uniformly at random from a calibration set, and H is the second moment matrix of these vectors, interpreted as a proxy Hessian."
> "For simplicity, we will focus in this section on rounding to the integers; subsequent sections will extend the analysis to finite grids."

Class of methods, Eq. (2), Section 3.1: Ŵ = Q(W + (W − Ŵ)U), U strictly upper-triangular, Q elementwise nearest or "standard unbiased rounding to the integers". Column order is fixed by U being upper triangular. LDLQ = Eq. (2) with U ← Ù from the LDL decomposition H = (Ù + I) D (Ù + I)ᵀ, Eq. (4).

Loss definitions, Eq. (5)–(6): L_worst(A, H) = sup_{W ∈ R^{m×n}} E tr(...); L_avg(A, H) = E_{W ~ Unif[0,1]^{m×n}} tr(...).

## 1. µ-incoherence — Definition 1, Section 3.3 (p. 4)

> "Definition 1. We say a symmetric Hessian matrix H ∈ R^{n×n} is µ-incoherent if it has an eigendecomposition H = QΛQᵀ such that for all i and j, |Q_ij| = |e_iᵀ Q e_j| ≤ µ/√n. By extension, we say a weight matrix W ∈ R^{m×n} is µ-incoherent if all i and j, |W_ij| = |e_iᵀ W e_j| ≤ µ ‖W‖_F / √(mn)."

Remarks given right after: "'most' n×n matrices are incoherent with µ = O(√log n) = Õ(1) because a random orthogonal matrix has entries with squared-magnitudes that concentrate around their mean of 1/n." and "Incoherence in W can be viewed as a form of outlier reduction".

Important reading: H-incoherence is about the eigenvector matrix Q (eigenvector/coordinate-axis alignment), not about the spectrum Λ. W-incoherence is max-entry relative to RMS entry (‖W‖_F/√(mn)), i.e., a max/RMS ratio bound. Section 4 states the random orthogonal transform "preserves the proxy quadratic form since tr(W̃H̃W̃ᵀ) = tr(WHWᵀ)" and the spectrum of H is unchanged.

Attribution: the definition is "a variant of the incoherence assumption that is specialized to our case [3, 24]" (citing Candès–Recht-style matrix-completion incoherence and the adaptive rounding paper).

## 2. LDLQ proxy-loss bounds

### Theorem 1 (Section 3.2, proof Appendix D)

> "Theorem 1. LDLQ is worst and average-case optimal amongst rounding methods which specify the linear feedback U as a function of H (not of W), and when rounding to the integers. That is, for all rounding methods A in the class described by Eq. (2), for all positive semi-definite H, and for Q as either nearest or stochastic rounding,
>   (m/4) tr(D) = L_worst(LDLQ, H) ≤ L_worst(A, H)   and   (m/c) tr(D) = L_avg(LDLQ, H) ≤ L_avg(A, H),
> where D is the matrix from the LDL decomposition of H, and c = 12 for nearest, c = 6 for stochastic."

Constants, exactly: worst case m/4 · tr(D) for BOTH nearest and stochastic (the adversarial W has entries 1/2 ± ε so every rounding error is ±1/2, proof p. 22–23). Average case m/12 · tr(D) for nearest, m/6 · tr(D) for stochastic (variance of integer rounding error of a Unif[0,1] entry: 1/12 nearest, 1/6 unbiased). The "1/4 vs 1/2" phrasing in the question does NOT appear in the paper; the nearest-vs-stochastic split is 1/12 vs 1/6 (average case), and 1/4 is the common worst-case constant.

Assumptions of Theorem 1: (i) rounding to the integers Z (no finite grid, no clipping/clamping); (ii) competitor class = Eq. (2) with U depending on H only, fixed column order; (iii) H PSD; (iv) Q ∈ {nearest, unbiased stochastic}; (v) optimality is "within-class", not global; (vi) L_avg is w.r.t. W ~ Unif[0,1]^{m×n}. Nothing about bounded weights is needed because the grid is unbounded.

### Lemma 2 (Section 3.3, proof Appendix D p. 24)

> "Lemma 2. Let H ∈ R^{n×n} be a µ-incoherent positive semi-definite symmetric matrix and let H = (Ù + I) D (Ù + I)ᵀ be its LDL Cholesky decomposition, where Ù is a strictly upper triangular matrix and D is a (non-negative) diagonal matrix. Then,
>   tr(D) ≤ (µ²/n) tr(H^{1/2})²."
> "To the best of our knowledge, this is a novel result using incoherence to obtain a bound on tr(D) that depends only on the spectrum of H."

Deterministic; only assumptions are PSD + µ-incoherent (Definition 1). Proof: by incoherence e_kᵀH^{1/2}e_k ≤ (µ²/n) tr(H^{1/2}); then an induction on a covariance recurrence (Lemma 8) shows tr(D) = min over feedback of tr(HΣ_n) ≤ (µ²/n) tr(H^{1/2})². PD case first, PSD by continuity.

### Lemma 3 (Section 3.3) — the baselines

> "Lemma 3. Let H be symmetric positive definite. In the worst case stochastic rounding achieves L_worst(Stoch, H) = (m/4) tr(H). In the average case nearest and stochastic rounding achieve L_avg({Near, Stoch}, H) = (m/c) tr(H), where c = 12 for nearest, and c = 6 for stochastic."

### Combined chain (Section 3.3, unnumbered display after Lemma 3)

> "consider H rank-k with µ²k < n. By Cauchy–Schwarz, tr(H^{1/2})² ≤ k tr(H)."
>   L_worst(LDLQ, H) ≤ (mµ²/(4n)) tr(H^{1/2})² ≤ (mµ²k/(4n)) tr(H) ≤ (m/4) tr(H) = L_worst(Stoch, H)
>   L_avg(LDLQ, H) ≤ (mµ²/(cn)) tr(H^{1/2})² ≤ (mµ²k/(cn)) tr(H) ≤ (m/c) tr(H) = L_avg(B, H),  B ∈ {Near, Stoch}
> "This shows that for sufficiently low-rank H, LDLQ is asymptotically better than plain nearest and stochastic rounding by a factor of µ²k/n."

So the headline improvement factor is µ²k/n, where k = rank(H) (or, via tr(H^{1/2})² ≤ k·tr(H), an effective rank), and µ is the incoherence of H's eigenvectors. Both ingredients are needed: low (effective) rank AND incoherence.

### Theorem 4 (Section 3.3) — spectrum alone cannot do it

> "Theorem 4. Consider all H̃ with the same spectrum as H. For any positive semi-definite H, the following holds. On the worst-case loss LDLQ achieves the same error as stochastic rounding, sup_{H̃: eig(H̃)=eig(H)} L_worst(LDLQ, H̃) = L_worst(Stoch, H) = (m/4) tr(H). On the average-case loss LDLQ achieves the same error as the corresponding rounding routine. ... sup_{H̃: eig(H̃)=eig(H)} L_avg(LDLQ*, H̃) = L_avg(B, H) = (m/c) tr(H)."
> "Note that the worst case for comparing LDLQ against these baselines occurs when H is diagonal ... Assuming incoherence as we do is a natural way to exclude such cases."

(The worst H̃ in the proof is the diagonal matrix Λ: then D = Λ and tr(D) = tr(H).) This is the paper's own proof that a spectral (rotation-invariant) quantity alone cannot explain any gain of LDLQ/GPTQ over RTN; the gain is entirely in the eigenvector–axis alignment that rotation changes.

### Lemma 5 (Section 4.1) — what the random Kronecker rotation guarantees

> "Lemma 5. Let H be a positive semi-definite matrix on R^{n×n} and W a matrix on R^{m×n}, and suppose that m = p_1···p_k and n = q_1···q_k. Let U_1..U_k, V_1..V_k be independent random orthogonal matrices on R^{p_i×p_i} and R^{q_i×q_i} respectively. Set U = U_1 ⊗ ··· ⊗ U_k and V = V_1 ⊗ ··· ⊗ V_k. Then VHVᵀ is µ_H-incoherent with probability at least 1 − δ, and UWVᵀ is µ_W-incoherent with probability at least 1 − δ, where
>   µ_H = A^{k/2} log^{k/2}(Ckn²/δ) = Õ(1)  and  µ_W = A^k log^k(2Ckmn/δ) = Õ(1)
> for some global constants A and C independent of n and k." (exponents reconstructed from garbled extraction; the paper says "poly-logarithmic in the matrix size")
> "In our experiments we use k = 2 factors."

So with k = 2, µ_H² ~ A² log²(2Cn²/δ) with an unspecified absolute constant A — the "factor µ²k/n" improvement has no explicit numerical constant.

### Finite grid: counterexample and Theorem 7 (Section 5.2)

> "In Section 3, we saw that LDLQ (equivalently, OPTQ) is optimal for minimizing the adaptive rounding objective. However, this analysis assumed rounding to the integers. In practice ... the 'real' LDLQ algorithm uses a clamp operation to restrict the range of quantized values. Is LDLQ still optimal when this small change is made? It turns out that the answer is no, as the following concrete example illustrates."
> Finite Grid Counterexample (Figure 4; code in Appendix C.3): H a small perturbation of (I_n + 1_{n×n} − e_n e_nᵀ)/n, W (m = 16) a small perturbation of 1_{m×n}/2, 4-bit grid [0,15]: "clamped LDLQ with nearest rounding is asymptotically worse, and the clamping to the finite grid is what causes it to be worse in this case."
> "This clamping issue does not seem to arise in practice; however, since it is possible we do need to take it into account to prove useful end-to-end bounds."

Fix = Algorithm 5 (Supplement): solve convex program (7) minimize tr(H RᵀR) over unit upper triangular R s.t. e_iᵀRᵀRe_i ≤ 1 + c ∀i; run with STOCHASTIC rounding and U = R⁻¹ − I.

> "Theorem 7. Suppose that we run Algorithm 5 (Supplement) to quantize a matrix W ∈ R^{m×n} by solving the objective (7). Then there exists an assignment of the algorithm's hyperparameters c and ρ such that with probability at least 1 − δ, all the quantized weights will be in range (no overflow or need for clipping) and
>   tr((Ŵ − W) H (Ŵ − W)ᵀ) = Õ( (1/(n² 4^b)) tr(H^{1/2})² ‖W‖_F² )."
> Explicit version, Theorem 15 (Appendix E): ≤ (A⁴ / (n² (2^b − 3)²)) · tr(H^{1/2})² ‖w‖_F² · log⁶(12Cmn²/δ), after two-factor orthogonal multiply and a rescaling that guarantees 1 ≤ w_ij ≤ 2^b − 2.
> "In practice, because clamping rarely causes issues, and because of the significant additional compute needed to solve this program, we always just use QuIP as described in the previous sections, which is equivalent to setting c large and using nearest rounding."
> Appendix C / Table 16: Algorithm 5 gives "improvements over LDLQ and LDLQ-RG on OPT-125m and OPT-350m, but diminishing improvements on OPT-1.3b ... we decide not to use it." and "in practice, we don't seem to encounter constructions of W and H that are bad for LDLQ/OPTQ. Therefore this 'clamping' issue seems to not be an issue in practice, especially as model size increases."

Net: the only finite-grid, b-bit, no-clipping guarantee in the paper (Theorem 7) is for an algorithm (Algorithm 5, stochastic rounding, convex program) that QuIP-as-run does NOT execute. QuIP-as-run (nearest rounding + clamp + LDL feedback) has Theorem 1/Lemma 2 only in the integer-grid idealization, and a documented counterexample on a finite grid.

## 3. LDLQ = OPTQ/GPTQ — Theorem 6, Section 5.1 (proof Appendix E p. 4598ff)

> "We prove a novel theoretical insight: QuIP without incoherence processing (i.e., LDLQ) is equivalent to a more efficient version of the OPTQ algorithm. That is, OPTQ falls under our class of adaptive rounding procedures with linear feedback, and is within-class optimal."
> "Theorem 6. OTPQ [8] falls within the class of adaptive rounding procedures with linear feedback as described by Eq. (2), and is equivalent to LDLQ in Section 3." (sic: "OTPQ")
> "Remarks. To the best of our knowledge, this equivalence yields the first theoretical analysis of OPTQ. Even though the two methods are equivalent, LDLQ is more efficient. OPTQ's implementation requires a matrix inversion of H, and two Cholesky decompositions. Our implementation of LDLQ performs no matrix inversion, and only one Cholesky decomposition."

How (proof): OPTQ, after fixing the first t−1 quantized entries, minimizes the proxy over the remaining entries: Δ_{t:n} = −Δ_{1:(t−1)} H_{1:(t−1),t:n} (H_{t:n,t:n})⁻¹. Writing H = Ũ D Ũᵀ (LDL, Ũ unit upper triangular), the trailing blocks factor as H_{t:n,t:n} = Ũ_{t:n,t:n} D Ũ_{t:n,t:n}ᵀ and H_{1:(t−1),t:n} = Ũ_{1:(t−1),t:n} D Ũ_{t:n,t:n}ᵀ, so Δ_{t:n} = −Δ_{1:(t−1)} Ũ_{1:(t−1),t:n} Ũ_{t:n,t:n}⁻¹; since Ũ_{t:n,t:n}⁻¹ e_1 = e_1, the only entry used, Δ_t = −Δ (Ũ − I) e_t. Hence ŵ_t = Q(w_t − (Ŵ − W)(Ũ − I) e_t), which is Eq. (2) with U = Ũ − I. Note the proof describes OPTQ as rounding "using nearest rounding to the grid and clamping"; the stated equivalence is at the level of the recursion (algorithm statements), with Q the same in both.

Empirical check (Section 5.1, Appendix C.2): "The quantized outputs of the OPTQ implementation [8] are shown to be exactly identical to the outputs of our LDLQ implementation. Synthetic random data was used, with W ~ Unif[0,1]^{1000×1000}." A script in the supplementary code verifies this. GPTQ's act-order (reorder by diag(H)) corresponds to the paper's LDLQ-RG variant, not to plain LDLQ.

## 4. "H is approximately low-rank" — exact wording and numbers

Section 3.3 (p. 4), the only main-text statement:
> "Theorem 1 gives exact expressions for the proxy loss, albeit with tr(D), which can be difficult to reason about. In Figure 1, we empirically observe that H is approximately low-rank: we visualize the spectrum of several randomly chosen H from OPT-2.7b, and observe that the spectrum decays rapidly. In fact, across all layers of OPT-125m to 2.7b models, a vast majority of H matrices have fewer than a quarter of eigenvalues > 1% of the max eigenvalue; see Supplement C for full details."

Caveats: (a) only OPT-125m..2.7b; no Llama/OPT-30B/66B rank statistics. (b) The "incoherent" column is essentially identical to "baseline" — consistent with rotation leaving the spectrum invariant. (c) tr(D)/tr(H) ≈ 0.38–0.54 means the exact Theorem-1 LDLQ-vs-RTN ratio on these Hessians is only ~2×, not the µ²k/n ≈ 0.02-scale factor the asymptotic bound suggests; the paper says the empirical check is "quick". (d) Absolute rank < 1 (0.43 at 2.7b) despite 262k calibration tokens ≫ n means H is numerically rank-deficient from the activations themselves, not from too few samples [my inference, not stated in the paper].

## 6. Paper's own limitations / future work (verbatim)

Appendix A.2 "Limitations":
> "The adaptive rounding [3] proxy objective considers each layer in isolation; it remains to be seen what other computationally tractable proxies could improve quantization. For example quantization methods do exist which consider interactions between layers, but so far have been too computationally expensive to be applied to the largest open LLMS."

Appendix A.1 "Broader Impacts": "Our work pushes the quantization of large language models into the 2 bits per weight regime. ... However our work is unaware to what ends those LLMs are used."

Conclusion (Section 7): "this theoretical analysis is the first for any quantization algorithm that scales to LLM-sized models." and "QuIP achieves the first viable two-bit quantization results for LLMs, especially at large model sizes, hinting at the feasibility of accurate 2-bit inference in LLMs."

Other self-stated caveats scattered in the text: Section 5.2 (clamping breaks optimality; Theorem 7 applies to an algorithm they do not run); Section 6 "Our modifications in QuIP-RG sometimes give an improvement over QuIP, but further study is required"; Appendix C "we decide not to use [Algorithm 5]".

## 7. What the report must change

Current citations in `reports/LLM 양자화 연구 아이디어 10선.md`: line 38 ("QuIP 비간섭성 정리" as rigorous layer-wise-proxy theory, tagged [V]) and line 209 (the "fewer than a quarter of eigenvalues > 1% of max" sentence used as evidence for ill-conditioned/low-rank activation Hessians).

1. Line 38 is correct in substance but should be sharpened: QuIP's rigorous results are Theorem 1 (within-class optimality of LDL feedback, integer grid, no clipping), Lemma 2 (tr(D) ≤ (µ²/n) tr(H^{1/2})²) and the derived factor µ²k/n vs RTN; the only b-bit/no-clipping bound (Theorem 7) is for Algorithm 5 (stochastic rounding + convex program), which QuIP-as-run does not execute, and Figure 4 is a finite-grid counterexample where clamped LDLQ is asymptotically worse than nearest. So "QuIP with guarantees" ≠ "the deployed QuIP has a guarantee".
2. Line 38's bundling with "GPTQ = Babai nearest-plane [2507.18553]": QuIP Theorem 6 (2023) already proves GPTQ/OPTQ ≡ LDLQ, i.e., Eq.-(2) rounding with U from the LDL of H (verified bit-exact on W ~ Unif[0,1]^{1000×1000}); the 2025 Babai paper is a lattice re-interpretation of the same recursion, not the first proof. Cite QuIP Thm 6 as the primary source for the equivalence.
3. Line 39 ("rotation cannot change ℓ2 norm, Hessian spectrum...") should add that this is exactly what QuIP's Theorem 4 says: with spectrum alone, sup over same-spectrum H̃ of LDLQ loss equals RTN's (m/4) tr(H) / (m/c) tr(H); the gain lives in the eigenvector–axis alignment µ, which rotation does change. The report's "spectrum invariance" argument therefore does not contradict QuIP; it restates Theorem 4, and the correct critique is that µ-incoherence controls only the proxy loss bound (and with unspecified constants A, C in Lemma 5), not end-to-end loss.
4. Line 209: keep the sentence but scope it: it is Section 3.3 / Table 6 on OPT-125m..2.7b only (approximate fractional rank 0.112 → 0.019 from 125m to 2.7b; absolute fractional rank 0.93 → 0.43), measured on OPTQ-style Hessians from 128×2048 C4 tokens. Also add the complementary number the report's sample-complexity argument needs: tr(D)/tr(H) is only 0.38–0.54 (Table 6), so the exact LDLQ-vs-RTN proxy ratio on real Hessians is ~2×, far from the asymptotic µ²k/n. And the absolute rank deficiency (0.43 at 2.7b with n_tokens ≫ d) is evidence that the activation covariance itself is rank-deficient, which bears directly on the report's κ_eff / n_eff argument (and on the 1% damping remark).
5. Any place the report implies QuIP's constants: worst case (m/4) tr(D) for both roundings; average (m/12) nearest, (m/6) stochastic. Do not write "1/4 vs 1/2".
6. QuIP's own limitation ("proxy considers each layer in isolation") is the same gap the report's §0.2 item 1 identifies; it can be quoted directly as the paper's self-assessment.
