## Q1. Objective and theory
**No theorem, lemma or proposition is present** (0 grep hits). The "theory" is an exact algebraic identity plus motivation:
- Eq. (6): logit perturbation Δa = <q_{t,j}, Δk_s>/√d. "the effect of a key error depends on the query and the softmax attention map, not only on ||Δk||²."
- Eq. (8), "exact decomposition": Δy_{t,j} = Σ_s Δp_{t,s} v_s W_{O,j}^T (key-induced) + Σ_s p̃_{t,s} Δv_s W_{O,j}^T (value-induced). This is an identity (add/subtract p̃ v), not a bound.
- Eq. (9) E_rec = ||K−K̃||²_F + ||V−Ṽ||²_F vs Eq. (10) E_out = ||δy_K + δy_V||². Claim (unproven, argued only): "Eq. (9) and Eq. (10) can favor different rotations".
- Optimized objectives (Sec 4.3–4.5):
  - Key, Eq. (14): L_K = E_{(t,j)∈D}[ D_KL(p_t || p_t^K(R_K)) + λ_K ||e_K||²/d_model ], with e_K = Σ_s (p^K_{t,s} − p_{t,s}) v_s W_{O,j}^T (values kept BF16 while calibrating keys). λ_K = 1.0.
  - Value, Eq. (16): L_V = E[ ||e_V||²/d_model ], e_V = Σ_s p̂^K_{t,s}(ṽ_s − v_s) W_{O,j}^T, under the already selected key rotation (sequential, keys first).
  - Parametrization Eq. (11)–(17): R = R⁰ exp(A − Aᵀ) per KV head, per layer; STE Eq. (18) ∂Q2/∂Z ≈ 1{|Z| ≤ τ_c}. 80 Adam steps, lr 0.02, weights frozen.
- So: attention-output (post-W_O) aware, data-driven, gradient-based through the real INT2 quantizer. Not MSE. Not closed-form.
- Ablation Table 4 (Qwen3-4B-Thinking, OSCAR base, KL term fixed, AIME25): cache-reconstruction error term 65.33±6.91, pre-W_O readout 62.67±2.79, post-W_O 70.67±2.79 (row order as printed: rec, pre-W_O, post-W_O). Note pre-W_O is *worse* than reconstruction, and std devs overlap for rec vs post-W_O; 5 seeds, one model, one benchmark.

## Q2. Query covariance / MLA / softmax bias
- Query-covariance weighting: **only implicitly**. The loss uses actual calibration queries q_{t,j} (30K-token pool of BF16 GPQA QKV traces), so query statistics enter through data, not via an explicit Σ_q = E[qqᵀ] weighting or a closed-form KLT/water-filling. The covariance-aware piece is inherited from the base rotation OSCAR [2605.17757] ("OSCAR derives key and value rotations from offline attention-aware covariance statistics"). OptR adds a per-head orthogonal correction on top of QuaRot or OSCAR.
- MLA latents: **not addressed**. 0 hits for MLA/latent/DeepSeek. Formulation is GQA only ("We consider a decoder-only Transformer layer ℓ with grouped-query attention (GQA)"). Models: Qwen3-4B-Thinking-2507, Qwen3-8B, Phi4-14B-reasoning-plus.
- Softmax bias: **not addressed as a bias**. No expectation/Jensen/unbiasedness analysis (0 hits for "unbias", "Jensen", "expectation"). Softmax enters (a) via the KL term in Eq. (14) and (b) via the attention-equivalent key centering: "subtracting the same µ from every key adds a query-dependent constant to all logits and leaves the softmax distribution unchanged" (Sec 4.1; App. Eq. 24). This is shift invariance, not a second-order bias result.
- Key centering detail (relevant to idea 9): App. Eq. (19) µ_{ℓ,h} = (1/N) Σ_{n,s} k^{RoPE}_{n,s,h} — a **single static per-channel mean of post-RoPE keys** from calibration, subtracted before rotation+INT2 (Eq. 20, implemented as k R − µR, precomputed µR). Not position-dependent (no R_m µ). Values are not centered ("shifting values would alter the attention output"). Table 3 (AIME25): OSCAR 63.33 → +Key Reparam 66.00 → +OptR 70.67 (Qwen3-4B); Phi4: 49.33 → 54.67 → 58.00.
- Setting: group-wise affine INT2, group 128, clip 0.96 (K) / 0.92 (V), 64 sink + 256 recent tokens BF16, 2.32 BPE at 64K.
- Key numbers, Table 1 (5 seeds, mean of 5 benchmarks): Qwen3-4B BF16 67.58, QuaRot-INT2 2.61, QuaRot+OptR 61.63, OSCAR 62.71, OSCAR+OptR 65.38. TurboQuant (no MP, 3.25 BPE, single run) 18.66 / 43.88 / 53.61.
- Table 2 RULER-NIAH 64K (3 seeds): Qwen3-4B BF16 88.76, QuaRot 0.72, QuaRot+OptR 46.86, OSCAR 55.72, OSCAR+OptR 69.58. Qwen3-8B BF16 84.22, QuaRot 0.04, QuaRot+OptR 70.02, OSCAR 57.54, OSCAR+OptR 68.65. Large gap to BF16 remains at 64K for the 4B model.

## Implications for the report
1. Ideas 1, 9, 10 cite OSCAR/Spend-Bits as the adjacent query-weighted work; OptR must be added as the strongest *empirical* output-aware competitor: it already optimizes post-W_O attention-output error (KL + output MSE) through the real INT2 path on GQA models. Any "output-aware / query-weighted transform" novelty claim must be restricted to (a) closed-form/second-order theory (OptR has none), (b) MLA latent with weight absorption (OptR is GQA-only), (c) softmax bias from heteroscedastic noise (OptR does not analyze bias), (d) bit allocation/water-filling (OptR uses uniform INT2).
2. Idea 9's "rotated mean subtraction" (R_m µ, position-dependent) must cite OptR's static post-RoPE per-channel key-mean centering (App. Eq. 19–20) as the baseline it improves on; the attention-equivalence argument (constant logit shift per query) is already published there.
3. Idea 10 risk sentence ("OSCAR/Spend-Bits authors could extend to MLA in months") should add OptR: its per-head correction R⁰exp(A−Aᵀ) is directly applicable to a latent, so the MLA idea's differentiator must be the head-summed weighting M and folding into W_UK/W_UV, not "output-aware" per se.
