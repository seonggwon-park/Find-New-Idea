## 0. Setup the theorems live on (Sec. 1.2–1.3, 2, 3)

- X ∈ R^{m×N}: calibration matrix, m samples (tokens) as rows, N input features; X_j = j-th column; X_{≥j} = (X_j, …, X_N). W ∈ R^{N×N'}, w ∈ R^N one column (one neuron). Layer output XW. P_A = AA† (projection onto col(A)), P_A^⊥ = I − AA†.
- X̃: "the input calibration dataset coming from the partially quantized model" (Sec. 1.2).
- Alphabets: infinite A_δ = {±kδ : k ∈ Z}; finite symmetric A_δ^b = {±kδ : k = −2^{b−1}, …, 2^{b−1}}, |A| = 2^b + 1. Q = round-to-nearest (MSQ/RTN). Q_stoc = unbiased stochastic rounding, E[Q_stoc(z)] = z (Sec. 1.3).
- Objectives (Sec. 2): OPTQ (2.1) min_Q ‖X̃W − X̃Q‖_F² ("or more commonly in practice"); Qronos / GPFQ (2.2) min_Q ‖XW − X̃Q‖_F². "Both objectives are instances of integer least-squares problems, which are NP-hard [17]."
- Algorithm 2.1 (OPTQ): H^{-1} = (XᵀX + λI)^{-1} = LLᵀ; for t = 1..N: q_t = Q(w_t^{(t−1)}); w_{≥t+1}^{(t)} = w_{≥t+1}^{(t−1)} + (q_t − w_t^{(t−1)}) L_{≥t+1,t}/L_tt. Lazy batching (block size B) is "mathematically equivalent to the B = 1 case" (fn. 4), so ignored.
- Key reduction (Sec. 3): "Running OPTQ (Algorithm 2.1) on X with regularization parameter λ > 0 … is equivalent to applying Algorithm 2.1 without regularization to the augmented matrix X̂ = [X; √λ I]" since XᵀX + λI = X̂ᵀX̂; X̂ "is always full rank with more rows than columns".
- Error at step t (3.1): e_t = Xw − Xw^{(t)} = Xw − Σ_{j≤t} q_j X_j − Σ_{j>t} w_j^{(t)} X_j; e_0 = 0, e_N = Xw − Xq.
- Lemma 3.1 ([42]): OPTQ lines (5),(6) ≡ greedy least squares: q_t = argmin_{p∈A} ½‖Xw − Σ_{j<t} q_j X_j − pX_t − Σ_{j>t} w_j^{(t−1)} X_j‖², then w_{≥t+1}^{(t)} = argmin_v ½‖Xw − Σ_{j≤t} q_j X_j − Σ_{j>t} v_j X_j‖². (Lemma A.1 is the same statement; the least-squares form works even when X is low rank or m < N, Cholesky does not.)

## 1. Q1 — OPTQ bounds, deterministic rounding (Sec. 3)

### Proposition 3.2 (OPTQ Error Evolution and Bounds) — λ = 0
> "Let X ∈ R^{m×N} be full rank with m ≥ N, and let w ∈ R^N. Running OPTQ (Algorithm 2.1) with λ = 0 (so H = XᵀX), the error defined in (3.1) satisfies
> (3.4) e_t = P^⊥_{X_{≥t+1}} (w_t^{(t−1)} − q_t) X_t + e_{t−1}, and e_N = Σ_{j=1}^N P^⊥_{X_{≥j+1}} (w_j^{(j−1)} − q_j) X_j.
> Moreover, the resulting quantized vector q satisfies
> (3.5) ‖Xw − Xq‖₂² = Σ_{j=1}^N |w_j^{(j−1)} − q_j|² ‖P^⊥_{X_{≥j+1}} X_j‖₂².
> In particular, this implies that when using the infinite alphabet A_δ
> (3.6) ‖Xw − Xq‖₂ ≤ (δ/2)·√N · min{ max_j ‖P^⊥_{X_{≥j+1}} X_j‖₂ , √(‖X‖_F²/N) }."

Assumptions: X full column rank, m ≥ N, λ = 0, **infinite** alphabet (no clipping; each rounding error |w_j^{(j−1)} − q_j| ≤ δ/2). (3.5) is an exact identity, (3.6) a bound.

Cold reading: ‖P^⊥_{X_{≥j+1}} X_j‖₂² is the squared Gram–Schmidt residual of X_j against the later columns = D_jj of the LDL decomposition of XᵀX in the reversed order. So (3.5) ⇒ ‖Xw − Xq‖₂² ≤ (δ²/4) Σ_j D_jj = (δ²/4) tr(D): this is exactly the Babai/QuIP tr(D) bound (QuIP Thm 1, 2507.18553 Thm 5). The paper never states the tr(D) form; (3.6) is a *loosening* of it (N·max_j or ‖X‖_F²). The paper's "first quantitative error bounds for OPTQ" claim (abstract, Sec. 1.1) is therefore contestable: QuIP (2023, their ref [4]) already gives L_worst(LDLQ,H) = (m/4)tr(D) for LDLQ ≡ GPTQ. What is genuinely new here is the λ-dependence (Thm 3.3), the sub-matrix-conditioning constant, the adversarial tightness constructions (App. D), and the ℓ∞ stochastic results (Sec. 4).

### Theorem 3.3 (General ℓ2 Error Bound when λ > 0)
> "Let X ∈ R^{m×N} and w ∈ R^N. Running OPTQ (Algorithm 2.1) with regularization parameter λ > 0 (so H = XᵀX + λI) and alphabet A_δ, the resulting quantized vector q satisfies
> (3.7) ‖Xw − Xq‖₂² + λ‖w − q‖₂² ≤ (δ²/4) · N · C₂(X, λ)².
> Consequently, we have
> (3.8) ‖Xw − Xq‖₂ ≤ (√N δ/2) · C₂(X, λ), and ‖w − q‖₂ ≤ (√N δ/2) · C₂(X, λ)/√λ, where
> (3.9) C₂(X, λ)² := min{ max{ max_{j≤N−m} λ‖X_j‖₂²/((σ_min^{(j)})² + λ), max_{j>N−m} ‖X_j‖₂² } + λ , ‖X‖_F²/N + λ },
> and σ_min^{(j)} denotes the smallest non-zero singular value of X_{≥j+1}. When N ≤ m, the index set {j ≤ N − m} is empty and the corresponding term is omitted."

Assumptions: **arbitrary** X (any m, N, rank), λ > 0, infinite alphabet A_δ, deterministic RTN. No randomness. Proof = Prop 3.2 on X̂ = [X; √λ I] + Lemma B.1: ‖P^⊥_{X̂_{≥j+1}} X̂_j‖₂² ≤ λ‖X_j‖₂²/((σ_min^{(j)})²+λ) + λ for j ≤ N−m, and ≤ ‖X_j‖₂² + λ for j > N−m.

### Corollary 3.5 (the interpretable form)
> "Let X ∈ R^{m×N} and w ∈ R^N. When running OPTQ (Algorithm 2.1) with regularization parameter λ > 0 (so H = XᵀX + λI) and alphabet A_δ, the resulting quantized vector q satisfies
> (3.10) ‖Xw − Xq‖₂ ≤ (√N δ/2) · min{ √(Tr(XᵀX)/N + λ) , ‖X‖_op }
> and
> (3.11) ‖w − q‖₂ ≤ (√N δ/2) · √(Tr(XᵀX)/(Nλ) + 1)."

Remark 3.6 (MSQ comparison): MSQ/RTN gives ‖Xw − Xq‖₂ ≤ (√N δ/2)‖X‖_op; "Since ‖X‖_op ≥ max‖X_j‖ ≥ √(Tr(XᵀX)/N), our result shows that OPTQ replaces the worst-case operator norm with a smaller quantity." Example: all columns identical with norm √m ⇒ ‖X‖_op = √(mN), MSQ bound (√Nδ/2)√(mN) = O(N√m) vs OPTQ (small λ) (√Nδ/2)√m = O(√(mN)) [reconstructed; the extracted text garbles the exponents]. "As λ → ∞, (3.10) reduces to ‖Xw − Xq‖₂ ≤ (√N δ/2)‖X‖_op and (3.11) reduces to ‖w − q‖₂ ≤ √N δ/2 which are the MSQ bounds."

Remark 3.7 (λ, alphabet size): "Corollary 3.5 heuristically justifies choosing λ as a small constant multiple of ‖X‖_F²/N. This aligns with the recommendation in [12], where λ is set to 0.01·‖X‖_F²/N." Finite alphabet A_δ^b suffices "provided 2^{b−1}δ ≥ ‖w‖_∞ + O(1)δ" IF ‖w − q‖_∞ ≤ O(1)δ, but: "While this heuristic is likely valid in most practical instances where OPTQ is applied, it cannot be made fully rigorous. In particular, there exist matrices X and vectors w for which Corollary 3.5 yields the pessimistic ℓ∞ upper bound ‖q‖_∞ ≤ ‖w‖_∞ + O(√N)δ, and this bound is sharp even for 'reasonably' chosen λ".

Tightness (App. D): D.2: for any α > 0 there exist X, w with λ = α‖X‖_F²/N such that "‖w − q‖_∞ ≳ √N, ‖X(w − q)‖_∞ ≳ √N when α is small compared to N. This holds despite ‖X‖_op = O(1), ‖w‖_∞ ≤ 1/2." ("an existential statement for each fixed α".) D.3 (λ = 0): "‖X(w − q)‖_∞ = ‖X(w − q)‖₂ = O(√N), and also ‖q‖_∞ = O(N), despite having ‖w‖_∞ ≤ 1." Hence "the ℓ2 bound in (3.11) is tight" (Remark 3.7) and deterministic OPTQ's ℓ∞ error can scale as √N (Sec. 4 intro).

Remark 3.4 (column ordering) — note the title: "A Heuristic Justification for Decreasing-Norm Ordering". It argues from (3.9)/(3.5) and Lemma B.2 (σ_min^{(j)} non-increasing in j for j ≤ N−m when X is in general position) and ends: "We rigorously justify descending norm ordering in the exact low-rank setting in Corollary 4.9." **Numbering caveat:** the contributions list (Sec. 1.1) says "we rigorously justify a heuristic … ordering features (columns of X) by decreasing norm before quantization (Theorem 3.4)", and elsewhere cites "Theorem 3.7", "Theorem 3.8", "Theorem 4.8" — but 3.4, 3.7, 3.8, 4.8 are all *Remarks* in the body. The rigorous ordering result is only Corollary 4.9 (exact low rank + stochastic rounding). The report must not cite this paper as a theorem-level justification of act-order in general.

Remark 3.8 (Generalization) — the only statement about unseen data (no bound, just a decomposition):
> "E_z |zᵀ(w − q_X)|² = (1/m)‖X(w − q_X)‖₂² + (w − q_X)ᵀ(E_z[zzᵀ] − (1/m)XᵀX)(w − q_X)."
> "This decomposition provides a sufficient condition for achieving low generalization error. First, … reconstruction error over the calibration set X … Second, … proximity between the original weight vector w and its quantized version q_X. This proximity can be enforced through regularization … Third, it depends on the quality of the empirical estimate of the second-moment matrix E_z[zzᵀ] by the empirical average (1/m)XᵀX".

## 2. Q1 — OPTQ bounds, stochastic rounding (Sec. 4)

Motivation (Sec. 4 intro, verbatim): "the lack of direct control on the magnitude of entries ‖w^{(t)}‖_∞ … makes it difficult to bound the quantization grid-size"; "Xq is the pre-activation feeding into the next layer … Guaranteeing a small ‖Xw − Xq‖_∞ would therefore enable quantizing these activations with a reasonable grid-size"; softmax/top-k: "if ‖Xw − Xq‖_∞ does not exceed half the entrywise gap within the sorted entries of Xw, the ordering—and thus the output—remains intact. An ℓ2 bound cannot guarantee this". And: "OPTQ can result in an error with ‖Xw − Xq‖_∞ scaling as √N".

Tool: Definition 4.1 convex order (X ≺_cx Y iff Ef(X) ≤ Ef(Y) for all convex f). Lemma 4.2: with Q_stoc, Xw − Xq ≺_cx N(0, Σ), Σ = (πδ²/2) Σ_j P^⊥_{X_{≥j+1}} X_j X_jᵀ P^⊥_{X_{≥j+1}} ⪯ (πδ²/2) max_j ‖P^⊥_{X_{≥j+1}} X_j‖₂² I. Proof technique from [39] (SPFQ) and [2] (Alweiss–Liu–Sawhney self-balancing walk).

### Theorem 4.3 (λ = 0)
> "Let X ∈ R^{m×N} be full rank with m ≥ N, and let W ∈ R^{N×N'}. Run OPTQ (Algorithm 2.1) with stochastic rounding operator Q_stoc, infinite alphabet A_δ, and λ = 0 (so H = XᵀX). Then for any p, p′ > 0 and any column w of W with quantized version q, we have
> ‖Xw − Xq‖_∞ ≤ δ√(2πp log N) · max_j ‖P^⊥_{X_{≥j+1}} X_j‖₂
> with probability at least 1 − √2 m/N^p. Moreover, for the full matrix W, the quantized matrix Q satisfies
> max_{i,j} |(XW − XQ)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · max_j ‖P^⊥_{X_{≥j+1}} X_j‖₂
> with probability at least 1 − √2 m/(N^p N′^{p′−1})."

Remark 4.4: for failure prob ε, max_{i,j}|(XW − XQ)_{ij}| ≤ δ√(2π log(√2 m N′/ε)) · max_j ‖P^⊥_{X_{≥j+1}} X_j‖₂. Remark 4.5: with w = 0, δ = 1, ‖X_j‖ ≤ 1 this is vector balancing, bound ‖Xq‖_∞ ≲ √(log N); "the best known bound is O(√(log min{m, N})) when the alphabet is binary" (Komlós conjecture) — so near-optimal.

### Theorem 4.6 (General ℓ∞ Error Bound when λ > 0)
> "Let X ∈ R^{m×N}, let W ∈ R^{N×N′}, and let λ > 0. Run OPTQ (Algorithm 2.1) with stochastic rounding operator Q_stoc, infinite alphabet A_δ, and H = XᵀX + λI. Then for any p, p′ > 0 and any column w of W with quantized version q,
> ‖Xw − Xq‖_∞ ≤ δ√(2πp log N) · C_∞(X, λ) and ‖w − q‖_∞ ≤ δ√(2πp log N) · C_∞(X, λ)/√λ
> with probability at least 1 − √2(m+N)/N^p. Moreover, with probability at least 1 − √2(m+N)/(N^p N′^{p′−1}), for the full matrix W the quantized matrix Q satisfies
> max_{i,j} |(XW − XQ)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · C_∞(X, λ) and
> max_{i,j} |(W − Q)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · C_∞(X, λ)/√λ,
> where C_∞(X, λ)² = max{ max_{j≤N−m} λ‖X_j‖₂²/((σ_min^{(j)})² + λ), max_{j>N−m} ‖X_j‖₂² } + λ, and σ_min^{(j)} denotes the smallest singular value of X_{≥j+1}."

(C_∞ is the first branch of C₂ in (3.9); no ‖X‖_F²/N branch.)

### Corollary 4.7 (interpretable ℓ∞ form)
> "… Then for any p, p′ > 0, the quantized matrix Q satisfies
> max_{i,j} |(XW − XQ)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · √(max_j ‖X_j‖₂² + λ)
> and max_{i,j} |(W − Q)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · √(max_j ‖X_j‖₂²/λ + 1)
> with probability at least 1 − √2(m+N)/(N^p N′^{p′−1})."

Remark 4.8 (alphabet size): if λ "is chosen on the scale of max_i ‖X_i‖₂², then Corollary 4.7 implies ‖q‖_∞ ≤ ‖w‖_∞ + O(√(log N))·δ"; finite alphabet suffices if "2^{b−1}δ ≥ ‖w‖_∞ + O(√(log N))·δ". With K := ‖w‖_∞/δ, bits needed are "O(log(K + √(log N))) in the stochastic case versus O(log(K + √N)) in the deterministic case." Note this needs λ ~ max_i‖X_i‖₂², which is much larger than the practical 0.01·‖X‖_F²/N; at the practical λ the ‖w − q‖_∞ bound carries a factor √(max_j‖X_j‖²/λ + 1) ≈ 10·√(max_j‖X_j‖²/(‖X‖_F²/N)).

### Corollary 4.9 (Low-rank X) — the only rigorous ordering result
> "Let X = UR where U ∈ R^{m×r} has orthonormal columns, R ∈ R^{r×N}, and r ≪ min(m, N). Assume R is in general position, i.e., any r columns of R are linearly independent. Run OPTQ using the least-squares formulation (Lemma A.1) with stochastic quantizer Q_stoc and the infinite alphabet A_δ. Then for any p, p′ > 0,
> max_{i,j} |(XW − XQ)_{ij}| ≤ δ√(2π(p log N + p′ log N′)) · max_{j>N−r} ‖X_j‖₂
> with probability at least 1 − √2 r/(N^p N′^{p′−1})."

Mechanism: e_{N−r} = 0 exactly (the first N−r coordinates' errors are fully absorbed by projection), so only the last r columns matter. Remark 4.10: hence sort by decreasing norm so that max_{j>N−r}‖X_j‖ is small. Requires the least-squares (not Cholesky) implementation, λ = 0, exact low rank, general position, stochastic rounding.

## 3. Qronos results (Sec. 5; λ = 0 "for simplicity", "readily extends")

Lemma 5.1: e_N = P^⊥_{X̃_{≥2}} P^⊥_{X̃_1} (Xw − X̃w) + Σ_j P^⊥_{X̃_{≥j+1}} r_j X̃_j, |r_j| ≤ δ/2 (Q) or δ (Q_stoc).

Proposition 5.3 (deterministic):
> "‖Xw − X̃q‖₂ ≤ ‖P^⊥_{X̃_{≥2}} P^⊥_{X̃_1} (Xw − X̃w)‖₂ + (δ/2)√N · min{ max_j ‖P^⊥_{X̃_{≥j+1}} X̃_j‖₂ , √(Tr(X̃ᵀX̃)/N) }" (5.3); stochastic: replace δ/2 by δ.

Comparison (5.4): OPTQ run on X̃ (as in the GPTQ repo) has e_N^{OPTQ} = (Xw − X̃w) + Σ_j P^⊥ r_j X̃_j, so its bound has ‖Xw − X̃w‖₂ unprojected. "Compared to OPTQ, the first term in the Qronos error in Proposition 5.3 is reduced by two successive projections … Moreover, when the quantized input X̃ is low rank and in general position, the first term of the Qronos error vanishes entirely. This offers a theoretical explanation for the observed performance advantage of Qronos over OPTQ." (Explanation at the level of upper bounds, not a separation theorem.)

Theorem 5.4 (stochastic): max_i |(Xw − X̃q)_i| ≤ max_i |(P^⊥_{X̃_{≥2}} P^⊥_{X̃_1}(Xw − X̃w))_i| + δ√(2πp log N) · max_j ‖P^⊥_{X̃_{≥j}} X̃_j‖₂ w.p. > 1 − √2 m/N^p. [Text shows X̃_{≥j}, elsewhere ≥j+1; likely a typo/extraction artifact.]

## 4. Q2 — MLP extension / Lipschitz activations: exact status

There is **no theorem** in the paper about multi-layer networks. The MLP Φ = ϕ^{[L]}∘A^{[L]}∘…∘ϕ^{[1]}∘A^{[1]} with componentwise activations is only *defined* (Sec. 1.2), and every result is stated for one layer (XW or Xw). The entire multi-layer content is one sentence in Sec. 6:
> "Our analysis focuses on the layer-wise calibration errors that motivate the design of OPTQ and Qronos, namely (2.1) and (2.2). Under added assumptions, for instance Lipschitz nonlinear activation functions, our results can be used to bound the calibration error induced by quantizing the weights of an L-layer MLP (see, e.g., [39, 40])."

[39] = J. Zhang & R. Saab, "SPFQ: A stochastic algorithm and its error analysis for neural network quantization"; [40] = J. Zhang, Y. Zhou, R. Saab, "Post-training quantization for neural networks with provable guarantees", SIMODS 5 (2023) 373–399. Those GPFQ/SPFQ papers do the layer-to-layer propagation; this paper does not redo it. The ℓ∞ results are explicitly motivated as the ingredient that would make such propagation useful ("Controlling ‖Xw − Xq‖_∞ bounds the required bit-width for the next layer's activation quantization", Sec. 1.1), but the composition is not carried out. Transformers (attention) are defined in Sec. 1.2 only to say "products of the form XW are ubiquitous".

## 5. Q3 — exact wording on transformers, cross-entropy, perplexity (Sec. 6)

> "It should also be possible to extend this framework to transformer layers used in LLMs, and to loss functions such as the cross-entropy loss but we leave this to future work. By contrast, obtaining guarantees directly for performance metrics such as perplexity and zero-shot accuracy on downstream tasks remains an open problem. That said, calibration error (which was the focus of this paper) is often a useful proxy for such empirical metrics, since smaller calibration error typically coincides with lower perplexity and higher zero-shot accuracy for LLMs."

So: transformers = "should be possible … future work"; cross-entropy = "future work"; perplexity/zero-shot = "remains an open problem"; the proxy link is asserted empirically ("typically coincides"), not proved.

## 6. Paper's own limitations / future work (Sec. 6, close paraphrase + quotes)

1. All results are single-layer calibration-error bounds on objectives (2.1)/(2.2); multi-layer MLP bounds need "added assumptions, for instance Lipschitz nonlinear activation functions" and are delegated to [39, 40].
2. Transformer layers and cross-entropy loss: "we leave this to future work".
3. Perplexity / zero-shot accuracy guarantees: "remains an open problem".
4. Generalization: "Another important direction for future work is generalization, that is, understanding when error bounds on calibration data also control error on unseen samples. While Theorem 3.8 [sic — Remark 3.8] provides a step in this direction, characterizing generalization to downstream tasks remains a challenge well beyond model compression. Bridging this gap is therefore an important direction for future work."
5. Implicit limitations not listed by the authors: (a) all bounds use an **infinite** alphabet (no clipping); finite alphabets are handled only heuristically (Remarks 3.7, 4.8) with an explicit admission that the deterministic case "cannot be made fully rigorous"; (b) ℓ∞ bounds require stochastic rounding, which is not what GPTQ/Qronos deployments use; (c) Qronos analysis sets λ = 0; (d) no experiments at all — the paper is purely theoretical; (e) deterministic worst case is tight at √N·δ (App. D), i.e. the ℓ2 guarantee is only a factor ‖X‖_op/√(Tr(XᵀX)/N+λ) better than RTN in the worst case.
