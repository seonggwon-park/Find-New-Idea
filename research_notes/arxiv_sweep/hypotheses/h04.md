# H5 판정: matched-input SNR_x가 4-bit unlearning 역전을 예측하는가, 그리고 on-grid base에서 RTN ≪ SR/dither < GPTQ 순서

작성일 2026-10-11. 입력은 triage의 H5와 judge/idea7.md "새 가설 1·2"다.
원문을 grep으로 확인한 논문은 2410.16454 (Zhang, ICLR 2025), 2602.13151 (LoRA unlearning), 2605.02196 (DurableUn), 2609.27355 (COLM 2026), 2605.15138 (MANSU), 2609.04526 (Scale-QLoRA)이다.
검색은 arxiv_search 11회(`--sort date --from 20260101` 4회 포함, 1회는 429 후 재시도)와 WebSearch 1회를 썼다. 자체 toy 시뮬레이션 1회(scratchpad/h04/sim.py)를 돌렸다.
논문 텍스트는 신뢰하지 않는 데이터로 다뤘고, 인용만 했다.

## 점수
- novelty 2/5, provability 3/5, feasibility 4/5.
- 권고: **fold_into_existing (아이디어 7)**.
  - SNR_x 자체는 Bernoulli 분산식을 활성 가중으로 다시 쓴 진단 통계량이다. 단독 논문이 되기 어렵다.
  - 대신 아래 "2×2 분해 실험"을 아이디어 7의 unlearning 절에 넣는다. 이 실험은 Zhang의 설명과 정리 7.1이 서로 모순된다는 점을 직접 검정하는 decisive 실험이다.
  - 세 체제 순서 주장(RTN ≪ SR < GPTQ)은 현재 형태로는 버린다(이유는 아래 4–5).

## 원문에서 확인한 사실 (가설을 바꿔야 하는 것)

1. **세 "역전" 사례는 서로 다른 체제다. 하나의 SNR로 순위를 매길 대상이 아니다.**
   - Zhang 2410.16454: BF16 target에서 full-FT로 unlearning한 뒤 RTN/AWQ/GPTQ로 PTQ한다. base는 격자 위에 있지 않다(위상 ~균일).
     - 수치: "an average of 21% of the intended forgotten knowledge in full precision, which significantly increases to 83% after 4-bit quantization" (abstract, l.31–32).
     - 설명은 구간 논증이다: "many model weights of the original model f and its unlearned model U(f) may map to identical quantized values" (l.304–307).
   - 2602.13151: LoRA unlearning을 merge한 뒤 RTN을 적용한다. base는 BF16이다.
     - 메커니즘 주장은 크기다: "α acts as a direct amplifier ... enforce the quantization threshold condition", "forces the update magnitude ... to be significantly higher" (l.301–323).
     - GPTQ/AWQ는 "exhibit similar failure modes"라고 인용만 하고 직접 돌리지 않았다(l.398–401).
   - DurableUn 2605.02196: 주 결과("INT4 induces recovery of up to 22×")는 **NF4 base 위의 LoRA 어댑터 가중치 자체**를 per-row absmax INT4로 양자화하는 시뮬레이터에서 나왔다(Eq.1, l.140–162). merged 모델 PTQ가 아니다.
     - App. D의 merged NF4 결과: GA의 FA는 BF16 0.070 → BnB-NF4 0.014, Sim-INT4 0.262. GradDiff는 0.043 → 0.003, Sim-INT4 0.151 (l.997–1034).
     - 즉 merged NF4에서는 "복귀 없음"이 아니라 FA가 **더 낮아진다**. 저자도 "further compresses adapter contributions"라고만 쓴다. 이것은 일반적인 품질 저하일 수 있고 SNR로 설명할 현상이 아니다.
   - 결론: H5의 "세 체제를 SNR_x가 순위 매긴다"는 비교 대상이 서로 다른 양자화 대상(merged 가중치 vs 어댑터 가중치)과 base 상태(BF16 vs NF4 on-grid)를 섞고 있다.

2. **정리 7.1(비편향성)은 Zhang의 설명과 정면으로 충돌한다. 이것이 H5에서 건질 수 있는 핵심이다.**
   - BF16 base에 고정 스케일 RTN을 쓰고 위상이 균일하면 E[Q(W0+d) − Q(W0)] = d다. 1차 효과는 기대값에서 보존된다.
   - 그러면 "같은 bin에 머문다"는 Zhang의 논증만으로는 **체계적** 복귀(21%→83%)가 나오지 않는다. 분산만 커지고 평균은 그대로다.
   - 따라서 관측된 체계적 복귀는 다음 셋 중 하나에서 와야 한다.
     - (a) base 자체의 양자화 노이즈 ε0 = Q(W0) − W0(RMS ≈ Δ/√12, d보다 수백 배 크다)와 forget loss 곡률의 2차 상호작용. 2609.27355 Theorem 1과 Fisher 비 F_f/F_r 논증(l.390–408)이 이 방향이다. 그런데 이 논문의 정리는 1차원 2차 근사 비례식일 뿐이고, 양자화 노이즈를 명시하지 않는다.
     - (b) 블록 스케일 재계산: absmax가 바뀌면 블록 전체가 다시 반올림된다.
     - (c) 낮은 SNR에서 forget 지표(ROUGE, KnowMem)의 비선형성.
   - SNR_x는 (c) 일부만 잡는다. (a)와 (b)에는 눈이 멀다.
   - 이 구분은 2×2 분해 실험으로 바로 검정할 수 있다(아래 실험 1).
   - 선행 연구 중 이 모순을 지적한 것은 찾지 못했다. Zhang §5, 2602.13151 §III, MANSU Lemma 1, DurableUn Prop. 1이 모두 "bin을 넘지 못하면 지워진다"는 결정론적 구간 논증을 쓴다.

3. **SNR_x는 등방 통계량과 거의 공선적이다. 그래서 반증 기준이 무승부로 끝날 가능성이 높다.**
   - full-FT GA/NPO의 선형층 업데이트는 Σ_t δ_t x_tᵀ다. LoRA도 forget 활성 방향으로 정렬된다. 두 경우 모두 d가 forget 활성에 정렬되어 있다.
   - toy 시뮬레이션(n=1024, heavy-tail 활성)에서 SNR_x/iso 비는 정렬된 델타에서 크기 1e-3~1e-2에 걸쳐 8.9–9.9로 거의 상수였다. 무작위 델타에서는 1.0이었다.
   - 즉 같은 모델 안에서 방법 간 차이는 주로 크기(|d|/Δ)에서 나오고, 크기는 등방 통계량도 똑같이 잡는다.
   - SNR_x가 등방 통계량을 이기려면 델타의 **정렬도**가 실험 조건마다 달라야 한다. 예: retain 정렬 vs forget 정렬, 무작위 노이즈 성분 주입.
   - 공식 자체도 |d_i| ≤ Δ일 때만 유효하다. |d|>Δ이면 분량 Δ|d|−d²가 음수가 된다(시뮬레이션에서 a=0.1일 때 SNR_x<0이 나왔다). 일반식은 frac(|d|/Δ)를 써야 한다.

4. **on-grid 세 체제 순서의 근거는 H5가 쓴 것보다 약하다.**
   - Scale-QLoRA 2609.04526의 SR 붕괴(AGNews 57%만 유지, l.1804)는 RTN 격자로 학습한 **QAT-LoRA**에 다른 규칙을 적용했을 때의 train–deploy 불일치다. 저자도 "The collapse is a train-vs-deploy mismatch, not 'a bad quantizer'"라고 쓴다(l.1850). 일반 LoRA 델타에서 SR이 GPTQ보다 나쁘다는 증거가 아니다.
   - 같은 논문에서 삭제의 원인을 "scale selection alone"으로 국소화한다. GPTQ를 MSE 격자 위에서 돌리면 75.6 → 92.1로 회복된다(l.2365–2378). "RTN = 결정론적 삭제"는 스케일 규칙에 의존한다.
     - DeepSeek AGNews에서는 RTN −3.6pp, GPTQ −2.0pp로 둘 다 거의 보존한다(l.2390).
     - RTN 15% 대 GPTQ 94%(l.736–738)는 한 모델(Llama Banking77)과 한 seed의 결과다.
   - toy(고정 스케일 on-grid, |d| 평균 0.05Δ)에서 Σd·x 평균 보존률은 RTN 0.54, SR 1.00, GPTQ 0.69–0.78이었다. 순서가 RTN < GPTQ < SR로, **H5가 예측한 SR < GPTQ와 반대**다.
     - 단층 선형 toy이므로 결정적이지는 않다. 다만 "GPTQ가 비편향 SR보다 낫다"는 것은 1차 이론에서 나오지 않는다. GPTQ는 보정 분포 X_cal에서 ‖(Q−W)X_cal‖을 최소화할 뿐이고, forget 활성에 대한 보존은 X_cal과 forget 분포의 겹침에 달려 있다.

5. **unlearning 내구성 이론은 이미 여럿 있다.** H5가 새로 보태는 것은 "비편향 + 분산 + 활성 가중"뿐이다.
   - MANSU 2605.15138: Lemma 1(bin 경계까지 거리 이상 업데이트하면 생존), Prop. 2("silently erased by NF4"), NF4 PTQ gap −0.040.
   - 2609.27355(COLM 2026): Theorem 1(곡률 비), AWQ/GPTQ 4-bit 결과(Table 3).
   - DurableUn Prop. 1(RA 보존 ⇒ 양자화 취약성, L-smoothness 가정).
   - stochastic rounding, dither, 보정 집합 선택으로 unlearning 내구성을 다룬 논문은 arXiv 검색 11회와 WebSearch에서 찾지 못했다.

## 날카롭게 한 가설 (아이디어 7에 넣을 형태)

H5′. BF16 base에 고정 스케일 양자화기를 쓰는 경우를 생각한다. Q(W_u) = W0 + ε0 + D̃로 분해한다. 여기서 ε0 = Q(W0) − W0이고, D̃ = Q(W_u) − Q(W0)는 E[D̃]=d, Var=Δ|d|−d²(|d|≤Δ)를 만족한다.
- 4-bit 지식 복귀는 D̃의 분산이 아니라 ε0와 forget loss 곡률의 상호작용에서 주로 온다.
- 반증 조건: W0 + D̃ 모델(base는 정확하고 델타만 재양자화)에서도 복귀의 절반 이상이 재현되면 H5′는 틀리고, SNR_x 경로가 맞다.
- 보조 예측: GPTQ의 보정 집합에 forget-set 활성을 섞으면 복귀가 줄어든다. 이 효과는 matched-input 잔차 ‖d·P⊥x_f‖로 예측된다. P⊥는 보정 공분산의 저에너지 부분공간이다.

## 수학 스케치

- 정리 A(고전, 증명 몇 줄): 위상 u_i ~ Unif이고 스케일이 고정이면 D̃_i ∈ {Δ⌊d_i/Δ⌋, Δ⌈d_i/Δ⌉}이고 E[D̃_i]=d_i, Var = Δ²f(1−f)다(f = frac(|d_i|/Δ)).
  - 독립 위상 아래에서 E[(D̃x)_j] = (dx)_j이고 Var = Σ_i Var_i x_i²다. 따라서 SNR_x는 정확한 1차 신호대잡음비다.
  - 선점: Gupta 1502.02551, El Arar 2207.10321, 2609.21834 Model 2 / Cor. 6.
- 따름정리 B(새것): L_f(W0+ε0+D̃)를 2차까지 전개하고 위상에 대해 기대값을 취한다.
  - E[ΔL_f] = g_fᵀd + ½ tr(H_f Σ_ε0) + ½ tr(H_f Σ_D̃) + O(‖·‖³).
  - D̃는 1차 항을 보존한다. 체계적 복귀는 tr(H_f Σ_ε0) 항이 g_fᵀd와 같은 부호를 가질 때만 생긴다. 예: GA 종점에서 H_f에 음의 곡률이 있으면 노이즈가 forget loss를 낮춘다.
  - Σ_ε0 ≈ (Δ²/12)I이므로 복귀 크기는 (Δ²/12)·tr(H_f) 대 |g_fᵀd|로 예측된다. 이것은 2609.27355의 Fisher 비를 양자화 노이즈 크기로 정량화한 형태다.
  - 가정은 세 가지다: 위상 균일(3/4-bit에서 2609.21834 Fig.2로 경험적 확인), 고정 스케일, 층 간 독립.
  - absmax 스케일 재계산과 GPTQ 오차 피드백은 가정을 깨므로 경험적으로만 다룬다.
- 증명 가능성은 중간이다. A는 자명하고 B는 표준 Taylor 전개다. 어려운 부분은 실제 네트워크에서 고차 항과 층 간 상관을 통제하는 것이다.

## 실험 스케치 (≈1 GPU-주, 7–8B)

1. **2×2 분해 (decisive, 학습 불필요).**
   - MUSE-News/Books 공개 target과 unlearned 체크포인트(Llama-2-7B; GA, GA_GDR, GA_KLR, NPO, NPO_GDR)를 쓴다.
   - 고정 스케일 RTN 4-bit g128로 네 모델을 만든다: {W0+d, Q(W0)+d, W0+D̃, Q(W_u)}.
   - 각 모델에서 KnowMem/VerbMem on D_forget과 retain 유틸을 잰다.
   - Q(W0)+d에서 복귀가 대부분 나오면 곡률 경로(H5′)가 맞다. W0+D̃에서 나오면 SNR 경로(원래 H5)가 맞다.
   - 위상 seed를 바꿔(W0에 Δ 이하 무작위 shift를 주고 subtractive dither) 분산을 추정한다.
2. **SNR_x 대 등방 통계량 회귀.**
   - 조건: 방법 5 × 학습률 3 × LoRA α 3 × 정렬 조작(retain 정렬 성분, 무작위 성분 주입) 2.
   - 반응 변수: 층별 복귀율. Spearman ρ를 비교하고 공변량으로 tr(H_f)·Δ²/12를 넣는다.
   - 반증 기준: 정렬 조작이 없는 조건에서 SNR_x와 iso의 ρ 차이가 0.05 미만이면 SNR_x는 기여가 없다고 판정한다.
3. **양자화기 비교.** RTN(absmax 재계산 / 고정 스케일), SR, subtractive dither, GPTQ(C4 보정 / C4+forget 보정)를 같은 unlearned 모델에 적용한다.
   - 예측: 고정 스케일 SR과 dither는 RTN보다 복귀가 적다(1차 보존). GPTQ+forget 보정은 GPTQ+C4보다 복귀가 적다.
   - SR < GPTQ 순서는 예측하지 않는다.
