# 새 아이디어 3 판정 실험 결과 (축소 대리 실험, 2026-10-11)

## 결론

부분 기각. 이론 부분은 실제 Hessian과 모순되지 않지만, 정상 캘리브레이션에서는 섹션이 미리 적은 실패 기준("δ ≥ 1e-2인 모든 층에서 gap < 0.3 bit이면 실무적 의미가 없다")에 그대로 해당한다. 실무적으로 의미 있는 gap은 캘리브레이션 토큰 수가 입력 차원보다 적은 특이(rank-deficient) Hessian에서만 나왔다.

## 설정

- 원래 계획(Llama-3-8B, Qwen3-8B, 224개 층)은 GPU·메모리 제약으로 불가능했다. Qwen2.5-0.5B의 linear 입력 Hessian 96개(층당 qkv·o·gate/up·down, n = 896 또는 4864)를 CPU에서 수집했다.
- 조건 두 가지:
  - full: wikitext-2 train에서 64개 × 1024토큰 = 65,536토큰(모든 n보다 큼).
  - starved: 512토큰 1개(n = 896 층에서 0 고유값 약 384개, n = 4864 층에서 약 4352개).
- damping δ ∈ {1e-4, 1e-2, 1e-1} × mean(diag H).
- 지표(고율 entropy-coded 모형, 2605.13768): gap = ½log₂(AM(D)/GM(λ)). D는 해당 기저의 Cholesky pivot.
  - 실측: Haar 회전 1회 후 정확한 pivot.
  - 예측: O&P Eq. 33(D_k ≈ E_k/E_{k−1}).
  - 비교: 회전 없는 GPTQ, PCA 기저 GPTQ, 이 아이디어의 two-point 최악 상한.
- 스크립트 `scripts/new_ideas/idea03_realH.py`. 원자료 `idea03_qwen05b_full.json`(첫 실행이 starved 단계에서 메모리 부족으로 종료되어 로그 `idea03_qwen05b_full.log`에서 복원), `idea03_qwen05b_starved.json`, 각 로그.

## 판정 기준별

1. **Spearman ≥ 0.7, |차이| ≤ 0.05 bit: 통과(starved δ = 1e-4 제외).** Eq. 33이 실제 Hessian의 gap을 거의 정확히 예측한다. 다만 Eq. 33은 O&P(2605.13768)의 식이므로, 이 결과는 O&P 근사를 실제 Hessian으로 확인한 것이지 이 아이디어의 새 기여를 확인한 것이 아니다. 토큰이 극히 부족하고 damping이 거의 없을 때(starved, δ = 1e-4)는 down_proj에서 0.28 bit까지 어긋났다.
2. **1% damping에서 0.3 bit를 넘는 층이 있는가: full에서 실패, starved에서 통과.** 정상 캘리브레이션에서는 96개 층 모두 0.3 bit 미만이었다.
3. **이 아이디어 고유의 결과(two-point 최악 점근식)의 진단 가치: 없음.** 실제 스펙트럼은 최악 스펙트럼과 멀어 상한이 실측보다 3–65배 크다. 층별 gap을 예측하는 것은 O&P의 Eq. 33이지 이 상한이 아니다.

## 해석

- 회전 GPTQ와 WaterSIC의 차이는 정상 캘리브레이션에서 1% damping 기준 중앙값 0.06 bit로 작다. 2605.13768이 Llama-3-8B에서 보고한 "0.1 bit 이내"가 0.5B 모델에서도 재현된다.
- gap이 커지는 것은 토큰 수가 입력 차원보다 적어 Hessian이 특이할 때뿐이다. 이는 O&P가 "we skip"으로 다루지 않은 경우다. 실무에서 이 조건이 자연스럽게 생기는 곳은 MoE 전문가 층이다(전문가마다 캘리브레이션 토큰이 적다). 이 방향은 이번 실험에서 검증하지 않았다 [가설].
- 따라서 이 아이디어는 "열린 문제에 대한 정확한 상수"라는 이론 노트로는 남지만, "실제 양자화에서 중요한 gap"이라는 주장은 기각한다. 실무적 가치가 남을 수 있는 유일한 경로는 특이 Hessian(MoE 전문가 등)으로 재포지셔닝하는 것이다.
