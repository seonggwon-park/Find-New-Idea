# T01 prior-art check: shared-seed stochastic rounding across DP replicas

Verdict: **survives_narrowed** (novelty 3/5). The stratified-dither fix is already published as correlated quantization (Suresh et al. 2022). The math core overclaims: for residues that are independent across ranks, stratified dither gives O(1/P), not O(1/P^2). The micro-batch half of the premise is false for TE and Quartet II. The cross-DP half of the premise holds in default Megatron-LM + Transformer Engine source.

## Premise checks

**P1 (cross-DP shared SR randomness in Megatron + TE): supported by the source code, not run.**
- Megatron `_set_random_seed`: `seed = seed_ + 100*pp_rank`. The rank offset `seed += 10*dp_rank` is applied only `if data_parallel_random_init` (default `False` in the signature).
- `model_parallel_cuda_manual_seed`: "Data parallel gets the original seed. data_parallel_seed = seed ... torch.cuda.manual_seed(data_parallel_seed)". Its docstring says the default state "is for data parallelism". A code comment in the same function says: "everything above is identical across peers by design".
- TE NVFP4 SR (quantizer.cpp l.2656-2666, cast.cpp l.173-185): `gen = at::get_generator_or_default<at::CUDAGeneratorImpl>(std::nullopt, at::cuda::detail::getDefaultCUDAGenerator()); philox_args = init_philox_state(gen, rng_elts_per_thread)`. So the SR bits come from the default CUDA generator, which is seeded identically on every DP rank and advanced by the same call sequence.
- Conclusion: in default configs, element (i,j) of the SR-quantized gradient on rank r very likely gets the same uniform as on rank s. Caveats: I did not run this, and a fork context or different kernel launch counts could break the alignment. **This needs a 2-GPU empirical check.**
- None of the FP4 papers states that SR seeds are, or must be, rank-distinct. 2610.00053 l.2070-2071 says only "Each distributed worker checkpoints its stochastic-rounding seed and counter offset so that a resumed run does not reuse random-number draws". That is about time reuse, not about whether ranks differ.

**P2 (micro-batch reuse): false for the stacks named.**
- In TE, every quantize call advances the Philox offset (`init_philox_state(gen, ...)`), so successive micro-batches draw fresh uniforms.
- Quartet II App. A l.1544-1545: "We apply identical rotations for every rotation group within a tensor for every micro-batch ... I.e., we re-randomize rotations per-tensor per-micro-batch." The rotation is reused across groups within one tensor and is fresh for each micro-batch. The gap claim misreads this.
- Quartet II l.546, "same rotation seed ωRHT" for both tensors, is required so the rotation cancels on the inner dimension. It is not a correlation flaw.
- Quartet II Corollary 3.1 (l.538) is a per-step unbiasedness statement only. That part of the gap claim is accurate.

**P3 (math core).**
- Shared-u covariance: Cov = E[min(f_r,f_s)] - E[f_r f_s] = 1/3 - 1/4 = 1/12, and the variance of the mean is 1/12 + 1/(12P). Correct; Monte Carlo agrees (P=64: P*Var = 5.429 vs 5.417 theory).
- **"Stratified u gives O(1/P^2)" is FALSE when residues are iid across ranks.** Var(mean e) = 1/(12P) + 1/(12P^2). That is only a 2x gain over independent SR (1/(6P)); Monte Carlo at P=64 gives P*Var = 0.0848 vs 0.1667. O(1/P^2) needs residues that are concentrated or equal across ranks, which is Suresh et al.'s small-input-deviation regime.
- Correct statement: independent SR = 1/(6P); stratified = 1/(12P) + O(1/P^2), which matches RTN's variance while staying unbiased; shared = 1/12 + 1/(12P).

## Closest work (read in full text)
- **2203.04925** Suresh, Sun, Ro, Yu, "Correlated quantization for distributed mean estimation and optimization" (ICML 2022). l.492-503: "Let π denote a random permutation of {0..n-1} ... γi uniform in [0,1/n) ... Ui = πi/n + γi ... Qi(xi)=1{πi+γi<xi}". l.155: "Correlated quantization uses shared randomness to introduce correlation between local quantizers at each client". **This is exactly the rank-stratified dither fix.**
- **2401.05518** Panferov, Demidovich, Rammal, Richtárik (2024): correlated quantization in nonconvex distributed optimization. l.1882: "the permutations require no extra communications, since they can be seeded."
- **2601.22813** Quartet II (Jan/Jun 2026): RNG design via rotation and SR seeds. App. A unbiasedness is verified on repeated single-device backward passes (1/B decay). It does not discuss DP ranks.
- **2509.25149** NVIDIA NVFP4 (Sep 2025): App. E.4.3 l.1709-1713 compares a "seed per instance" with a "single fixed seed" for the RHT sign vector and finds "no improvements from inducing randomness at every transform instance". That is evidence that correlated *rotation* randomness is harmless. It does not address SR across ranks.
- **2511.00874** Liu et al. (Nov 2025): l.578-584 assumes "stochastic rounding is performed independently on each number ... SR variance diminishes as the mini-batch size b increases" (Lemma 3, 1/b). T01 targets exactly this independence assumption.
- **2609.39185** Khilar (Sep 2026), "Low-Discrepancy Dither for Quantized Recurrent State Caches". Uses Weyl (low-discrepancy) dither over the *time* axis instead of iid SR (Prop. 1: error O(log T)). Observation 1 (space-time aliasing): correlated dithers across entries hurt (l.1209). This is the same idea of choosing the correlation structure of the dither along the axis being summed, applied to inference recurrence rather than DP replicas.
- **2603.06060** SR survey (El Arar et al. 2026), l.328-340: cites patents. NVIDIA (Chang & Yu) seeds LFSRs by block or layer position, which would share randomness across replicas. Mellanox (Oltchik et al.) distributes seeds across a network for reproducible in-switch SR. No correlation analysis.
- 2610.00053 (Hu 2026, per-worker SR seed checkpointing, l.2070), 2609.39813 (reuse vs. independent rounded copy), 2504.20634 (SR with few random bits) and 2607.18745 (independent-error product identity): adjacent, no overlap.

## What overlaps
- The stratified/permuted shared-randomness quantizer across clients, U_i = π_i/n + γ_i: 2203.04925 and 2401.05518.
- The general principle that correlation structure of the dither along the summation axis is a design variable: DME literature, and 2609.39185 for the time axis.
- The independent-SR 1/b batch scaling: 2511.00874.

## What remains
1. The **diagnosis**: default Megatron-LM + Transformer Engine NVFP4 SR draws from a CUDA default generator that is seeded identically across DP ranks. Their SR errors are then (by source reading) fully coupled across replicas, which breaks the 1/P assumption that 2511.00874-style analyses use. No paper states or measures this.
2. The shared-u plateau result, Var -> 1/12 + 1/(12P) (at most a 2x reduction for any P). It is elementary but not in the literature for SR.
3. The **transfer to quantize-then-GEMM-then-all-reduce**: Wgrad_r = sum_t (dY_t + e_t) x_t^T. Here cross-rank coupling enters only through E[x]^2, so it is concentrated in nonzero-mean or massive-activation channels. The DME papers average the quantized vector itself.
4. The **corrected stratified claim**: stratification gives about 1/(12P), the RTN-level variance with unbiasedness, so at most a 2x gain over independent SR. It is not O(1/P^2).

## Significance (main-track reviewer view)
The independent-seed fix is a one-line change (`--data-parallel-random-init` or a rank offset on the SR generator). So the paper rests on showing that the shared-seed floor measurably hurts loss at realistic DP (P = 64 to 1024). At large P the shared-seed SR noise stays O(1) while sampling noise falls as 1/P, so SR noise could dominate late in training. If a loss gap appears at scale, this is a solid systems-numerics note (workshop or main-track short). Otherwise it reads as a bug report. The stratified extension adds at most 2x and has DME precedent.
