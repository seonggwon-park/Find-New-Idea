# T09 prior-art check: group-shared quantization perturbation and the Jensen degenerate-group bound

**Verdict:** survives_narrowed. The theorem is preempted, the mechanism-level empirical claim is preempted, and the causal conclusion has a premise problem. **Novelty:** 2/5.

## 1. The theorem is already published (2605.07689, 2026-05-08)

Nie et al., "Gradient Starvation in Binary-Reward GRPO", Proposition 2 (text lines 205-224):

> "D(p, G) = p^G + (1-p)^G is convex for G >= 2 (its second derivative G(G-1)[p^{G-2} + (1-p)^{G-2}] >= 0), Jensen's inequality gives: D_real = E_x[D(p_x, G)] >= D(p̄, G) = D_iid ... Furthermore, by second-order Taylor expansion: D_real >= D_iid + G(G-1)/2 Var(p_x) · min[p^{G-2} + (1-p)^{G-2}]."

- **What is the same:** this is T09's math core. It has the same convex function, the same Jensen step and the same Taylor gap term.
- **What differs:** only the source of randomness in p. Nie et al. average over prompt heterogeneity (p_x); T09 averages over perturbation draws (p'). Changing the label on the random variable is not a new theorem.
- **Measured evidence:** D_real = 0.90 versus D_iid = 0.56 at G=2 on Qwen3.5-9B GSM8K (lines 230-235).

Esther Xin's 2609.06386 (2026-09-06) builds on the same reference. Its Table 3 (line 456) reports a "degenerate-group rate roughly 6.3–6.5× this reference". It names within-group correlation (ICC) and between-prompt heterogeneity as the causes of the inflation. It also notes that the 7B policy was AWQ-quantized (line 644), but it does not isolate a quantization effect.

## 2. The mechanism is already shown empirically (2608.09805, 3PO, 2026-08-10)

Venkatkrishna, Daheim and Gurevych:

- **Lines 102-103:** "B3PO samples a single weight perturbation per gradient step, which makes it dependent on a single weight draw and can limit group diversity ... C3PO divides each GRPO group across N independently sampled weights".
- **Line 312:** "B3PO samples a single perturbation θ̂ per batch and reuses it across all prompts and groups."
  - This is exactly the "group-shared perturbation" regime that T09 attributes to QeRL/AQN.
- **Abstract (line 34):** "using multiple parameter samples consistently produces fewer zero-advantage groups".
- **Line 1034 and Sec. 5.3:** an ablation over N ∈ {1, 2, 4, 8, 16}. "all runs with N >= 2 outperform the single-perturbation baseline". Figure 3 counts the zero-advantage groups each method rescues.

So the claim "per-sample perturbation reduces wasted groups versus a shared one" is already shown empirically, with an ablation. 3PO has no theorem, but the theorem itself is in 2605.07689. 3PO never mentions QeRL or quantization (grep found no matches).

## 3. 2602.02555 (PSN-RLVR) is not a per-rollout method

The idea's author describes PSN-RLVR as "per-rollout parameter noise". Its text says otherwise:

> "At the beginning of each iteration, we apply additive Gaussian noise ... θ̃ is held fixed for the entire rollout" (lines 419-428).

The appendix (line 1608) says the G training rollouts are sampled "under πθ̃". PSN-RLVR is therefore also a group-shared design. It cites QeRL as concurrent work (lines 223-228) but never contrasts shared with per-sample noise.

## 4. Premise checks

| Premise | Status |
|---|---|
| 2510.11696 Sec. 3.2 says "A key limitation of quantization errors is their deterministic nature" | TRUE. Text line 563. |
| AQN noise is "resampled once per step" | PAPER SAYS OTHERWISE, CODE AGREES WITH T09. The paper (line 585) says "This vector is not fixed but is resampled for each forward pass". The official NVlabs/QeRL code says otherwise (see below). |
| BF16 LoRA + AQN 89.7 vs NVFP4 LoRA + AQN 90.8 (GSM8K, 7B) | TRUE. OpenReview forum zw8zxMJJlm, author reply table (revised Table 7). |
| 2605.20402 abstract: "grid noise raises the policy's entropy" | TRUE. Lines 21-22. It also says "Before each rollout, AQN perturbs weights" (line 680). |
| Neither paper distinguishes group-shared from per-sample perturbation | TRUE for QeRL and 2605.20402. FALSE for the field: 3PO does exactly this. |

How the official QeRL code handles AQN:

- `trl_trainer/noise_scheduler.py::generate_gaussian_noise` draws one Gaussian tensor per RMSNorm and calls `module.weight.add_(noise)` on the vLLM model.
- It is called from `grpo_trainer.py` lines 1364-1369 inside the weight-sync routine.
- That routine runs only when `self.state.global_step != self._last_loaded_step` (lines 1542-1544).
- Result: in the code, one draw per optimizer step is shared by every prompt and every one of the G rollouts. This contradicts the paper's "each forward pass".
- Side note: `add_` accumulates unless the layernorm weights are reloaded from the trainer. They are reloaded only if layernorm parameters appear in the PEFT state dict. Otherwise the injected noise is a random walk.

Rebuttal numbers (OpenReview, Qwen2.5-7B-Instruct, GSM8K / MATH500):

| Setting | GSM8K | MATH500 |
|---|---|---|
| BF16 LoRA | 88.1 | 77.0 |
| BF16 LoRA + AQN | 89.7 | 77.8 |
| NVFP4 LoRA | 88.5 | 76.8 |
| NVFP4 LoRA + AQN | 90.8 | 77.4 |
| Full-parameter | 91.2 | 77.4 |
| Full-parameter + AQN | 91.4 | 77.2 |

- Quantization alone adds +0.4 on GSM8K. That is within the reported std (±0.9 to ±1.2).
- AQN alone on BF16 adds +1.6.
- So "generic noise explains most of the gain" is a fair reading for GSM8K, from single runs.

## 5. Logical problems in the hypothesis itself

1. **A deterministic error has no Jensen gap.** For a fixed quantization error, p' is a single number, Var(p') = 0, and P(degenerate) = D(p_Q, G). Whether this is above or below D(p, G) depends only on whether p_Q is closer to 1/2 than p.
   - An entropy-raising deterministic error on easy prompts (p near 1) lowers degeneracy.
   - So "cannot be GRPO's exploration mechanism" does not follow. The Jensen bound only ranks shared-random against iid-random noise at equal marginal. It says nothing about shared noise versus no noise.
2. **"Gains come from entropy, not parameter-space diversity" is not implied by the theorem.** The evidence for it is the rebuttal table, not the math.
3. **"At matched KL strictly reduces wasted groups" is not a theorem.** Matching KL does not match the marginal success probability p̄. The strict claim holds only for iid draws from the same perturbation distribution. In that case the marginal matches automatically and the claim is just Jensen again.

## 6. What remains

All of the following are empirical, quantization-specific statements:

- **(a) Documented regime.** QeRL/AQN as implemented is group-shared (one draw per optimizer step across all G). The paper text misdescribes this as "resampled for each forward pass".
- **(b) Measured, not assumed, Jensen gap.** Measure Var(p') across AQN draws per prompt to get the predicted extra degeneracy, and compare it with measured zero-advantage rates.
- **(c) Matched-marginal controlled comparison inside the QeRL pipeline.** Compare:
  - shared AQN,
  - per-rollout AQN (C3PO-style chunking, N ∈ {1, 2, 4, G}),
  - temperature raised to match token entropy.
- **(d) Quantization-native per-sample diversity.** Draw the randomization of the quantizer itself per rollout: stochastic rounding seed, random Hadamard rotation seed, or block-scale dither. This turns "free" quantization error into iid noise across a group at no extra memory cost. No paper was found for this (searched stochastic rounding, randomized quantization, random rotation and dither combined with rollouts, GRPO and RL).

## Sharpened hypothesis

In QeRL-style NVFP4-LoRA GRPO, both the fixed quantization error and the AQN noise (one draw per step in the official code) are shared across every rollout in a group. Two predictions follow:

1. Redrawing the quantizer's randomization (rotation or stochastic-rounding seed) or the AQN draw per rollout chunk lowers the zero-advantage-group rate, by the amount 2605.07689's convexity bound predicts from the measured Var(p'). It also gives higher final accuracy than shared AQN at matched mean token entropy.
2. Shared AQN matched in entropy by temperature alone reproduces most of QeRL's +2.7 GSM8K gain.

The math is cited, not claimed.

## Significance

A main-track reviewer would see the theorem as a restatement of 2605.07689 Prop. 2. They would see the shared-versus-chunked perturbation finding as 3PO's B3PO-versus-C3PO result. The remaining contribution is a sound diagnostic of QeRL (a paper-versus-code discrepancy, plus an entropy-matched control) and possibly a free per-rollout quantizer-randomization trick.

- **Workshop:** viable.
- **Main track:** needs (d) to deliver clear gains over 3PO/C3PO at lower cost.
